# 病人評估

## 關節痛評估

### 四個鑑別方向
- **關節炎 vs 非關節炎**
  - 關節炎：廣泛、較深的疼痛；主動與被動活動都因痛受限；關節腫（滑膜增生、積液、骨性變大）；活動有 crepitation；關節變形
  - 非關節炎：單點或局部壓痛；主動活動時痛；較少腫、摩擦音、變形
- **急性 vs 慢性**（{{o|以 6 週區分}}）：{{r|急性要想到**結晶性關節炎、感染性關節炎**}}（考105）
- **發炎 vs 非發炎**
  - {{g|發炎：紅腫熱痛、全身症狀、CRP／ESR 高、**晨僵 > 30 分鐘**、**活動後改善**}}
  - {{g|非發炎：痛但不腫熱、ESR／CRP 可正常、晨僵較短、**活動後更痛**}}
- **單關節 vs 多關節**（{{o|≥ 4 個為多關節}}，Harrison 定義）
  - {{r|單關節：外傷、結晶性、感染性（細菌、黴菌、TB）}}（考104、107）
  - {{r|多關節：OA、RA、PsA}}（考104；104 年考古說 OA 以單關節較常見）

### 依關節位置鑑別
- {{p|**RA 不太侵犯 DIP**}}
- {{r|**DIP 關節炎要想到 OA 和 PsA**}}（考104、105、107、108）
- {{r|OA：DIP 的 **Heberden's nodes**、PIP 的 **Bouchard's nodes**}}（考109、112、113）
- 手部各關節：DIP → OA、PsA、reactive arthritis；PIP → OA、SLE、RA、PsA；MCP → RA、pseudogout、hemochromatosis；1st CMC → OA；wrist → RA、pseudogout、淋菌性關節炎、carpal tunnel

# SLE 紅斑性狼瘡

## 臨床表現（考111）

### 各器官
- 發燒、疲累
- 皮膚：
  - Acute：malar rash、photosensitivity
  - Subacute：annular、papulosquamous
  - Chronic：discoid、lupus profundus
  - {{p|口腔或鼻腔潰瘍：**以硬顎為主、比較不痛**}}
  - Nonscarring alopecia
- 肺：pleuritis、ILD、pulmonary hemorrhage、shrinking lung syndrome
- 腸胃：腸繫膜血管炎
- 心血管：心包膜炎、心包膜積水、肺動脈高壓
- 腎臟：蛋白尿、血尿、腎功能變差
- 神經：癲癇、psychosis、transverse myelitis
- 血液：溶血（AIHA、MAHA）、{{o|白血球 < 4,000、淋巴球 < 1,000、血小板 < 100,000}}、血栓（APS）
- {{g|關節痛：**年輕女性 SLE（non-erosive）**；**中年女性 RA（erosive）**}}

### 狼瘡腎炎（ISN／RPS 分類）
- I：Minimal mesangial，預後好
- II：Mesangial proliferative，預後好
- III：Focal
- {{r|IV：**Diffuse proliferative**}}（考105）
- V：Membranous
- VI：Advanced sclerosing，準備透析，藥物幫助不大

### 狼瘡腎炎治療
- {{b|類固醇 + （MMF 或 cyclophosphamide）±（calcineurin inhibitor 或 belimumab 或 obinutuzumab）}}
- {{b|**Belimumab**：第一個治療狼瘡腎炎的生物製劑（2020 NEJM），也是第一個 SLE 生物製劑}}
- {{b|**Voclosporin**（2021 Lancet）：併用 MMF 比單用 MMF 效果好}}
- {{b|**Obinutuzumab**（type II anti-CD20）：治療狼瘡腎炎（2025 NEJM）與 SLE（2026 NEJM）}}
- 2024 ACR 指引：可考慮 triple therapy

## 實驗室檢查（考107、111）

### 自體抗體
- {{p|**ANA**：2019 criteria 診斷 SLE 都需要 **ANA ≥ 1:80**}}；甲狀腺疾病、其他免疫疾病、年長者也可能陽性 → {{g|**敏感度高、特異度低**}}
- {{r|**Anti-dsDNA**：特異度高，**與疾病活性相關**}}（C3／C4 也與活性相關）（考114）
  - anti-TNF 藥物可能使 dsDNA 轉陽
- {{r|**Anti-SSA（Ro）／SSB（La）**：乾燥症抗體，SLE 也可能有；**SSA 可穿過胎盤 → congenital heart block 或 neonatal lupus**}}（考104、114）
- **Anti-Sm**：特異度較高
- {{r|**Anti-histone**：藥物引起的 lupus}}（考105）
  - {{g|藥物：**procainamide、hydralazine**、disopyramide、minocycline、anti-TNF}}
- {{r|**Anti-ribosomal P**：可能與 **CNS 侵犯**有關}}（考106）
- APS 抗體：陽性要 {{o|**12 週後**}}再驗一次排除偽陽性
- {{r|RPR 或 VDRL 可能**偽陽性**}}（考105）
- {{r|Cytokine 異常}}（考107、114）：**Type I IFN** 上升、IL-2 下降、IL-6、IL-10、IL-17A、IL-21、IL-23、BLyS／APRIL 上升

### 考題重點
- {{r|對診斷 SLE 最有幫助的抗體：**anti-dsDNA**}}（考114）
- {{r|Type I IFN 在 SLE 的正確敘述：**血中濃度與疾病活動度呈正相關**}}（考114）
  - {{g|錯誤：FDA 尚未核准 anifrolumab（已核准）；血中測不到；血球無 IFN 基因表現（有 IFN signature）；與狼瘡腎炎不相關}}
- {{r|2 週大新生兒雙側臉部環狀斑塊 → 懷疑 neonatal lupus → **檢查母親有無 anti-SSA／Ro**}}（考114）
- {{r|18 歲 SLE 合併肺高壓與心包積水，**不正確**的是：**TGF-β 在致病機轉中沒有角色**}}（考114）

## 診斷（考107、108）

### 分類標準
- 1997 ACR criteria
- {{r|2012 SLICC criteria}}（考107）：≥ 4 項（至少 1 臨床 + 1 免疫），或切片證實狼瘡腎炎合併 ANA 或 anti-dsDNA 陽性
- {{r|**2019 ACR／EULAR criteria**}}（考111、112）：
  - {{p|先決條件 **ANA ≥ 1:80**（HEp-2 細胞）}}
  - 要先排除其他可解釋的原因（感染、癌症等）
  - {{o|總分 **≥ 10 分**}}

## 治療

### 藥物
- 類固醇
- {{r|**Hydroxychloroquine（Plaquenil）：基本上所有 SLE 病人都建議長期使用**}}（考108）
- Azathioprine（Imuran）：健保有給付
- MPA／MMF（Myfortic、CellCept）：健保給付需腎臟切片
- Calcineurin inhibitor：cyclosporine、tacrolimus、voclosporin
- {{b|**Cyclophosphamide**：嚴重器官侵犯（狼瘡腎炎、CNS、血管炎）}}
- {{b|**Belimumab**：抑制 BAFF → 抑制 B cell}}；第一個 SLE 生物製劑（皮膚狼瘡、降低 SLE 活性），第一個狼瘡腎炎 RCT 成功的生物製劑（健保給付於 MMF 治療 6 個月效果不佳者）
- Rituximab（anti-CD20）：RCT 沒成功，但臨床常用於 SLE 併發症
- {{r|**Anifrolumab**（抗 type I IFN receptor subunit 1）：降低 SLE 活性}}（考112、114）
- Telitacicept（anti-BLyS／APRIL，2025 NEJM）
- {{g|生物製劑整理：**降低 SLE 活性** → belimumab、anifrolumab、obinutuzumab；**治療狼瘡腎炎** → belimumab、obinutuzumab}}

### 懷孕用藥
- {{r|**懷孕可用：cyclosporine、類固醇、azathioprine、hydroxychloroquine、sulfasalazine**}}（考106、107、114）
- {{p|**MPA／MMF、cyclophosphamide 懷孕不能用**}}
- {{r|正確敘述：**HCQ 被美國 FDA 歸類為對胎兒無危險的藥物**}}（考114）
  - {{g|錯誤：MTX、MMF、cyclophosphamide 對胎兒無害；anti-TNF 對胎兒有危險}}

# Antiphospholipid syndrome（APS）

## 表現與檢驗

### 重點
- 症狀（考104、106）：**血栓**（動脈、靜脈都可能）、**懷孕併發症**
- 檢驗：
  - {{r|**aPTT 延長**}}（考105）
  - Antiphospholipid antibodies：anticardiolipin Ab（IgG／IgM）、anti-β2-glycoprotein I Ab（IgG／IgM）、**lupus anticoagulant**
  - {{r|要驗 SLE profile，因為常合併 SLE}}（考106）
  - 血小板低

## 診斷（考109）

### 標準
- {{p|臨床與檢驗**至少各符合一項**}}
- 臨床：
  - 血管栓塞（不分動靜脈與小血管）
  - 懷孕相關：
    - {{o|一次以上、懷孕 **10 週以後**的胎兒死亡}}（胎兒型態正常）
    - {{o|一次以上、**34 週以前**因子癲前症／子癲症或胎盤功能不足導致早產}}
    - {{o|**三次以上**、**10 週以前**不明原因流產}}
- 檢驗（{{o|間隔 **12 週**驗兩次}}）：
  - Lupus anticoagulant：{{p|warfarin、heparin、DOAC 會造成偽陽性}}
  - Anti-β2GPI IgG／IgM、anticardiolipin IgG／IgM
- 2023 ACR／EULAR 有新 criteria（看看就好）

## 治療

### 重點
- {{r|**Warfarin** 治療血栓：}}{{o|INR 目標 **2～3（靜脈）或 3～4（動脈）**}}；{{r|**懷孕不能用 warfarin，要用 LMWH**}}（考108）
- {{p|DOAC 目前沒有 RCT 證據比 warfarin 好}}（2018 Blood）
- {{r|**Low-dose aspirin**}} {{o|75～100 mg/day}}：初級或次級預防（考108）
- 合併 SLE 者加 hydroxychloroquine
- {{b|Catastrophic APS：可考慮血漿置換（PP）}}

# Rheumatoid arthritis（RA）

## 臨床表現（考108）

### 重點
- {{p|小關節為主、對稱、慢性}}；影像有 **erosion**；ulnar deviation、swan neck
- 皮膚：**rheumatoid nodule**（伸側）
- {{r|心肺：**ILD**、肋膜積水、心包膜炎}}（考104、105、114）
- 腎臟：amyloidosis
- {{r|眼睛：**episcleritis**}}（考104、105）；{{g|RA 很少 uveitis（AS、PsA、Behçet 才常見）}}
- 血液：**Felty's syndrome**（脾腫大 + neutropenia）
- {{r|**Atlantoaxial subluxation（C1-C2）**}}（考104）

## 實驗室檢查

### 重點
- {{r|**RF**：特異度較低（HBV／HCV 等慢性感染也可能陽性）}}（考109、111）
- {{r|**Anti-CCP（ACPA）**：偽陽性少、**特異度高**，可預測早期 RA}}（考104、105、106、108、111、113、114）
  - {{p|**考試同時出現 RF 與 anti-CCP，幾乎都要選 anti-CCP**}}
- {{g|ESR／CRP 高（SLE 的 CRP 一般不高）；血小板高（SLE 可能低）}}
- {{r|基因：**HLA-DRB1**（含 **HLA-DR4**）}}（考104、110）、PTPN22、PADI4

### 考題重點
- {{r|34 歲女性雙側 PIP、MCP 腫痛，對診斷 RA 最有幫助：**ACPA**}}（考114）
- {{r|早期 RA 治療 2 個月後乾咳、呼吸困難，懷疑 ILD → 最有效的檢查：**HRCT**}}（考114）

## 診斷：2010 ACR／EULAR criteria（考105、112、113）

### 計分（≥ 6 分）
| 項目 | 內容 | 分數 |
|---|---|---|
| 關節 | 1 個大關節 | 0 |
| | 2～10 個大關節 | 1 |
| | 1～3 個小關節 | 2 |
| | 4～10 個小關節 | 3 |
| | > 10 個關節（至少 1 個小關節） | 5 |
| 血清學 | RF 與 ACPA 皆陰性 | 0 |
| | 低陽性（{{o|≤ 3 倍 ULN}}） | 2 |
| | 高陽性（{{o|> 3 倍 ULN}}） | 3 |
| 急性期反應物 | CRP 與 ESR 正常 | 0 |
| | CRP 或 ESR 異常 | 1 |
| 病程 | {{o|< 6 週}} | 0 |
| | {{o|≥ 6 週}} | 1 |

- 排除 DIP、1st CMC、1st MTP 關節
- 大關節：肩、肘、髖、膝、踝；小關節：MCP、PIP、2nd～5th MTP、thumb IP、wrist

## 治療

### DMARD
- {{r|**第一線：MTX monotherapy**}}（MTX 禁忌可改 sulfasalazine 或 leflunomide）（考110）
  - 台灣：健保規定第一線為 MTX；leflunomide 需 MTX 有禁忌或副作用才能用
  - 國外建議單一 DMARD；台灣為了申請生物製劑，一開始常用兩種 DMARD
- {{p|台灣規定用兩種 DMARD **6 個月**無效才能申請健保生物製劑或 JAK inhibitor}}
- {{b|**MTX**}}：{{o|15～25 mg/週（台灣一般 15 mg/週）}}，搭配**葉酸**解毒
- {{b|**Leflunomide**}}：{{o|10～20 mg/天（健保要求 20 mg/天）}}
- {{b|**Hydroxychloroquine**}}：小心視網膜病變、皮膚變黑
- {{b|**Sulfasalazine**}}：{{p|G6PD 缺乏禁用；懷孕可用}}

### 生物製劑與小分子藥物
- {{b|**Anti-TNF**：etanercept、infliximab、adalimumab、**certolizumab（懷孕可用）**、golimumab}}（考105）
  - {{p|**最容易造成肺結核再活化**}}
  - {{p|**心臟衰竭不能用**}}
- {{b|Anti-IL-6：tocilizumab}}
- {{b|T-cell co-stimulation inhibitor：abatacept（CTLA4-Ig）}}
- {{b|B cell depletion：rituximab（anti-CD20）}}
- {{b|JAK inhibitor}}：{{p|小心**靜脈血栓、帶狀疱疹**}}
- {{g|**可以單用（不必併用 MTX）：JAK inhibitor 與 tocilizumab**}}

### 生物製劑風險管理
- 有感染時不可使用
- {{p|用前要驗 **latent TB**（QuantiFERON 或 T-SPOT）；陽性要先吃 **INH 至少 1 個月**才能開始，**共吃 9 個月**}}
- 篩檢 HBV、HCV
- JAK inhibitor 增加帶狀疱疹

# Spondyloarthritis（SpA）

## 分類

### 重點
- 包含：ankylosing spondylitis（AS）、psoriatic arthritis（PsA）、reactive arthritis（ReA）、enteropathic arthritis、juvenile-onset SpA、undifferentiated SpA
- 另分 axial SpA（脊椎、骨盆、胸廓）與 peripheral SpA
- {{p|**Seronegative**：RF、ANA 陰性}}

## Psoriatic arthritis（PsA）

### 症狀（考108、110）
- {{r|關節炎，但和 RA 不同，**PsA 可以侵犯 DIP**}}（考105、107、110）
- {{r|**Dactylitis（sausage finger）**}}（考108）
- {{r|**Enthesitis**：Achilles、plantar fascia 附著點}}（考108）
- {{g|Uveitis：**PsA 為 posterior**；**AS 為 anterior**}}
- {{r|指甲病變：**pitting、onycholysis**}}（考110）
- 診斷：**CASPAR criteria**（有發炎性關節、脊椎或附著點疾病，加以下 ≥ 3 分：目前有乾癬 2 分，乾癬病史或家族史 1 分；乾癬指甲病變；RF 陰性；dactylitis；影像有關節旁新骨形成）

### 治療（EULAR 2023）
- {{b|單／寡關節炎、enthesitis、中軸 → 第一線 **NSAID**，可局部注射類固醇}}
- {{b|無效或多關節炎 → DMARD（MTX、leflunomide、sulfasalazine）}}
- {{b|3 個月沒改善或 6 個月未達標 → 生物製劑或 JAK inhibitor}}
  - Anti-TNF
  - {{r|**Anti-IL-17**：ixekizumab（Taltz）、secukinumab（Cosentyx）、brodalumab（Lumicef）、bimekizumab（Bimzelx）}}（考106）
  - Anti-IL-12/23：ustekinumab；anti-IL-23：guselkumab、risankizumab
  - JAK inhibitor：tofacitinib、upadacitinib
- PDE4 inhibitor：apremilast（2024/3 健保只給付乾癬）
- {{b|中軸型 PsA：anti-TNF、anti-IL-17、JAK inhibitor}}

## Ankylosing spondylitis（AS）與 axial SpA

### 概念
- Axial SpA = radiographic axSpA（r-axSpA，就是 AS）+ non-radiographic axSpA（nr-axSpA）
- {{r|早期 AS 的 X 光可能沒變化 → 發展出 **ASAS criteria** 早期診斷}}（考108）
  - {{o|用於下背痛 **≥ 3 個月**且 **< 45 歲**起病}}
  - nr-axSpA：符合 axSpA 但不符合 AS 的 X 光標準（靠 **MRI**）
  - {{r|**MRI 在早期 AS 診斷的價值**}}（考104、106、107、112）

### Inflammatory back pain（IBP）（考108、114）
- {{o|符合 **2 項**懷疑、**4 項以上**可確診}}（Harrison 定義），{{p|**注意：沒有 ESR／CRP 這類檢驗項目**}}
  - {{o|發作年紀 < 40 歲}}
  - Insidious onset
  - {{p|**運動後改善**}}
  - {{p|**休息不會改善**}}
  - 夜間背痛，甚至痛醒
  - {{o|晨僵 ≥ 30 分鐘}}
  - 兩側臀部交替疼痛（alternating buttock pain）

### 流行病學
- {{o|好發 20～30 歲}}
- {{r|**HLA-B27**：約 10% 的人有；AS 病人 **7～9 成**有；有 B27 的人 **< 10%** 會得 AS}}（考105、113）
- {{r|其他基因：ERAP1、IL-23R}}（考105）；IL-22 與新骨形成（syndesmophyte）有關

### 其他表現
- {{r|Enthesitis（例如 Achilles tendon）}}（考107）
- {{r|**Anterior uveitis：最常見的關節外表現**}}（考105、106）
- {{r|發炎性大腸炎}}（考105）

### 治療
- {{b|**NSAID：第一線**}}
- {{b|Sulfasalazine：只用於周邊關節炎}}
- {{r|NSAID 無效 → **anti-TNF、anti-IL-17、JAK inhibitor（upadacitinib、tofacitinib）**}}（考106、107、111、112）

### 考題重點
- {{r|17 歲男性清晨全身僵硬、背腰痠痛，活動 30 分鐘後恢復；ANA、RF 陰性，IgA 上升 → **ankylosing spondylitis**}}（考114）

## Reactive arthritis（考104、107）

### 重點
- 舊稱 **Reiter's syndrome**：{{g|**arthritis、urethritis、conjunctivitis**}}
- {{p|手腳：**keratoderma blennorrhagicum**（膿漏性角皮病）}}
- {{p|**Circinate balanitis**（環狀龜頭炎）}}
- 可有 enthesitis、dactylitis
- 相關病原：**Chlamydia、Campylobacter、Salmonella、Shigella、Yersinia**

# Systemic sclerosis（SSc）

## 分類

### 重點
- **Localized scleroderma**：沒有內臟侵犯，分 morphea 與 linear scleroderma
- **Systemic sclerosis**：
  - {{p|**Limited**：遠端肢體（膝、肘以下）皮膚變硬}}；CREST 是其中一種
  - {{p|**Diffuse**：近端與遠端都會硬化}}
- {{r|**Limited 不是 diffuse 的前驅期**；limited 進展較慢、diffuse 較快}}（考108）
- {{g|CREST：Calcinosis、Raynaud、Esophageal dysmotility、Sclerodactyly、Telangiectasia}}

## 臨床表現（考110、114）

### 各器官
- 皮膚：變厚、puffy finger、甲褶微血管異常、皮下鈣化、telangiectasia
- {{r|血管：**Raynaud phenomenon**}}（考110）；也見於 DM／PM、SLE、MCTD
- {{p|腎臟：**scleroderma renal crisis**：AKI、高血壓、MAHA}}
- {{r|腸胃：吞嚥困難、**GAVE（watermelon stomach）**、intestinal pseudo-obstruction}}（考110）；食道問題也見於 DM／PM
- {{r|心肺：心肌纖維化、**ILD**}}（考114）、{{r|**肺動脈高壓**}}（考104、105）
  - {{g|國外風濕病合併肺高壓最常見是**硬皮症**；**台灣最常見是 SLE**}}

## 檢查（考106）

### 抗體
- ANA：{{o|約 9 成陽性}}
- {{r|**Anti-Scl-70（anti-topoisomerase I）：與 ILD 相關**}}（考104、106、108）
  - {{p|考試同時出現 anti-centromere 與 anti-Scl-70（問 ILD），選後者}}
- {{r|**Anti-centromere**：肺高壓、CREST（limited）}}（考108）
- **Anti-RNA polymerase III**：scleroderma renal crisis、快速皮膚進展、同時發生的癌症
- Anti-Th/To：肺高壓、ILD
- PM-Scl：overlap syndrome（calcinosis、ILD、肌炎）
- {{g|**Nucleolar pattern** 的 ANA → 想到 SSc（U3-RNP、Th/To、PM-Scl）}}

### 診斷：2013 ACR／EULAR（≥ 9 分）
- {{o|雙側手指皮膚增厚延伸到 MCP 近端：**9 分**（單獨就可分類）}}
- 手指皮膚增厚：puffy fingers 2 分、sclerodactyly 4 分
- 指尖病灶：digital tip ulcer 2 分、pitting scar 3 分
- Telangiectasia 2 分、甲褶微血管異常 2 分
- 肺：PAH 2 分、ILD 2 分
- Raynaud 3 分
- SSc 特異抗體（ACA、Scl-70、RNA pol III）3 分

## 治療

### 重點
- {{r|**Prednisone > 15 mg/day 會增加 scleroderma renal crisis**}}（考108）
- {{b|皮膚：MMF、MTX}}
- {{r|肺：MMF、cyclophosphamide、rituximab、**nintedanib（Ofev）**、tocilizumab}}（考114）
- {{r|**Scleroderma renal crisis：ACEI**}}（考108、112）
- 骨髓移植（2018 NEJM）

### 考題重點
- {{r|48 歲女性寒冷時手指變白變紫、乾咳、吞嚥困難、手指與臉皮膚變厚、**ANA nucleolar pattern** → **systemic sclerosis**}}（考114）

# Idiopathic inflammatory myopathies（IIM）

## 分類（考108）

### 重點
- {{r|**Polymyositis**：**CD8+ T cells**}}（考108）
- {{r|**Dermatomyositis**：**CD4+ dendritic cells、B cells**，可能與 type I IFN（最可能是 IFN-β）路徑有關}}；有皮疹；{{p|男性小心**鼻咽癌**、女性小心**乳癌與婦科癌**}}（考108）
- {{r|**Immune-mediated necrotizing myositis（IMNM）**：病程較快；**anti-SRP、anti-HMGCR（statin 暴露）**}}（考108）
- {{r|**Inclusion body myositis（IBM）**：anti-cN-1A；**遠端**肌肉也會無力、不對稱；CK 可能正常}}（考108）

## 臨床表現

### 重點
- {{r|多為**近端**肌肉無力，但 **IBM 會遠端無力**}}（考110）
- DM 皮膚表現（病理：cell-poor interface dermatitis）：Gottron sign／papules、heliotrope rash（偏紫）、shawl sign、V sign、holster sign、**mechanic's hands（Jo-1）**、皮下鈣化
- {{r|肺：**ILD**（MDA-5 預後不好）}}（考110）
- 甲床微血管擴張

## 檢查

### 重點
- {{r|CK、aldolase、AST、LDH 上升}}（考107）；ESR／CRP 上升
- EMG 或 MRI（MRI 可導引切片）
- {{r|肌肉切片}}（考106）
- 抗體（ANA 不一定陽性）：
  - {{r|**Anti-Jo-1**：antisynthetase syndrome：非侵蝕性關節炎、Raynaud、mechanic's hands、ILD}}（考104、106、107、110）
  - {{r|**Anti-Mi-2**：DM 皮疹表現}}（考112）
  - Anti-SRP：necrotizing myositis
  - {{r|**Anti-HMGCR**：necrotizing myositis（statin 暴露史）}}（考108）
  - {{r|**Anti-MDA5**：**快速進展 ILD、預後差**；palmar Gottron papules（inverse Gottron）、digital ulcers}}（考108、111、112）
  - {{r|**Anti-TIF1γ、anti-NXP2**：與**癌症**相關}}（考112）
  - Anti-cN-1A：IBM

![肌炎抗體與臨床表型：antisynthetase、necrotizing、皮膚、癌症](img/1_fPWCG1iqR-522D_J47WgSY55EZUQXeo/p028.webp)

### 治療
- {{r|類固醇}}（考107）
- {{b|MTX、azathioprine；cyclophosphamide、rituximab}}
- {{b|IVIG for DM（2022 NEJM）}}
- Dazukibart（IFN-β 單株抗體）for DM（2025 Lancet，phase II）

# Sjögren's syndrome

## 症狀（考106、108）

### 重點
- 疲倦、眼乾、口乾
- {{p|**唾液腺腫大 → 想到 Sjögren、IgG4-RD**}}
- 關節炎（多為 non-erosive）
- {{r|**Type I RTA**}}（考106）
- {{r|**ILD**}}（考106）
- {{r|**淋巴瘤**的預測因子：舌萎縮、持續腮腺腫大、purpura、mixed type II cryoglobulinemia、**低 C4**、自體抗體（RF、anti-Ro52／Ro60、anti-La）、小唾液腺大量淋巴球浸潤}}（考112、114）
  - 淋巴瘤以 **glandular MALT lymphoma** 最常見
- {{r|**50% PBC 有 Sjögren**}}（考106、108）
- {{r|PD-1／PD-L1 inhibitor 最常引起的自體免疫併發症為 Sjögren}}（考112；講師註明查不到出處）

### 考題重點
- {{r|最容易發生 extranodal lymphoma 的系統性自體免疫病：**Sjögren's syndrome**}}（考114）

## 檢查與診斷

### 重點
- ANA 幾乎都陽性（因為 SSA）；{{p|RF 常陽性（不代表是 RA）}}
- SSA（Ro）／SSB（La）、Schirmer test、lip biopsy
- 要排除：HCV、HIV、頭頸部放療、sarcoidosis、GVHD、anticholinergic 藥物、**IgG4-RD**、amyloidosis
- {{p|新 criteria 只強調 **SSA**；至少要 **SSA 或 lip biopsy** 其中一個陽性}}

### 治療
- 人工淚液
- {{b|副交感神經促進劑：pilocarpine、cevimeline}}（{{p|青光眼、氣喘不能用}}）
- Hydroxychloroquine 改善疲倦的證據不足

# Mixed connective tissue disease（MCTD）（考107）

## 重點

### 表現與檢驗
- ANA 要 **high titer**；RF 可能陽性
- {{r|**Anti-U1 RNP 為主要抗體**}}（考105、107）
- Raynaud、關節炎、**puffy hands**、肺動脈高壓、肺纖維化
- 診斷（Alarcón-Segovia）：{{o|anti-RNP ≥ 1:1600}} + 以下 ≥ 3 項（需含滑膜炎或肌炎）：手腫、滑膜炎、肌炎、Raynaud、acrosclerosis

# Vasculitis 血管炎

## 分類

### 依血管大小
- **大血管**：Takayasu arteritis、giant cell arteritis
- **中血管**：polyarteritis nodosa
- **小血管**：ANCA-associated vasculitis、cryoglobulinemia、IgA vasculitis

## Takayasu arteritis

### 重點
- {{o|**< 50 歲**亞洲女性}}較常見
- 侵犯主動脈與其分支 → stenosis、aneurysm
- {{r|好發位置：**subclavian > common carotid > abdominal aorta > renal**}}（考109）
- {{o|兩側肢體血壓差 > 10 mmHg}}；ESR、CRP 高
- 主要靠影像診斷
- {{b|治療：類固醇、DMARD、TNFi、tocilizumab}}

## Giant cell arteritis（GCA）

### 重點
- {{r|**> 60 歲**老人較常見}}（考109）
- {{r|侵犯 **temporal artery** → 頭痛、視力模糊}}（考107）
- {{p|**Jaw claudication**}}；常有發燒、疲累
- {{p|常合併 **PMR**}}：ESR 高、肩膀與髖部疼痛（bursitis）、類固醇效果好
- 診斷：影像（超音波 **halo sign**、MRA、PET）或血管切片
- {{b|治療：類固醇、MTX、**tocilizumab**（2017 NEJM）、upadacitinib（2025 NEJM）}}

## Polyarteritis nodosa（PAN）

### 重點
- Necrotizing **nongranulomatous** vasculitis
- {{p|**與 HBV 可能有關，但與 ANCA 無關**}}
- 皮膚潰瘍、腹痛、腎梗塞 → 血尿、**mononeuritis multiplex**、{{p|**睪丸疼痛**}}
- 器官侵犯：腎 60%、肌肉骨骼 64%、周邊神經 51%、腸胃 44%、皮膚 43%
- {{r|診斷：血管攝影（**microaneurysm**）或 CTA；切片}}（考108）
- {{b|治療：類固醇、cyclophosphamide}}

## ANCA-associated vasculitis

### 分類（考104）
- **GPA**（granulomatosis with polyangiitis，舊稱 Wegener）
- **MPA**（microscopic polyangiitis）
- **EGPA**（eosinophilic GPA，舊稱 Churg-Strauss）

### ANCA 與鑑別（考107、108）
- {{r|**cANCA → anti-PR3**}}（考105、112、113、114）
- {{r|**pANCA → anti-MPO**}}（考104、114）
- {{r|**pANCA 較常見於 MPA；cANCA 較常見於 GPA**}}（考105、109、112、113、114）
- {{r|**GPA 侵犯上呼吸道與鼻竇（可造成 saddle nose）**；**EGPA 常表現氣喘**}}（考105）
  - {{g|Saddle nose 常見原因：GPA、relapsing polychondritis、syphilis}}
- {{g|病理：**MPA 為 non-granulomatous**；**GPA 為 granulomatous**}}
- 2022 GPA、MPA、EGPA 都有新的分類標準

### 治療
- MPA／GPA：reduced-dose 類固醇似乎就有效（2020 NEJM）
- {{b|**誘導緩解：cyclophosphamide 或 rituximab**}}（不嚴重可用 MMF 或 MTX）
- {{b|**維持：rituximab、azathioprine**}}
- {{b|**復發：rituximab 優於 cyclophosphamide**}}（RAVE trial）
- {{b|EGPA：**mepolizumab**（anti-IL-5，2017 NEJM）、benralizumab（anti-IL-5Rα，2025 NEJM）}}
- {{p|血漿置換（PLEX）：2020 NEJM 顯示無效}}
- {{b|**Avacopan**（C5a receptor inhibitor，2021 NEJM）}}

### 考題重點
- {{r|血管炎致病機制最正確：**cANCA in GPA**}}（考114）
  - {{g|錯誤：pANCA in GCA；T cell in lupus vasculitis；IgG immune complex in HSP（應為 IgA）；IgE immune complex in Churg-Strauss}}

## Cryoglobulinemic vasculitis

### 重點
- **Type I**（10%）：單株 Ig，與 B cell 增生疾病相關；屬凝血問題，多發小中血管**栓塞**，偶見血管炎
- **Type II**（65%）與 **Type III**（25%）mixed：慢性感染（**HCV**）、B cell 疾病、自體免疫；補體介導的免疫複合體沉積 → 小血管炎
- 表現：palpable purpura、關節炎、周邊神經病變、腎絲球腎炎
- 檢驗：{{p|**RF 陽性、補體低**}}、ESR 高、貧血、HCV
- {{b|治療：HCV 相關 → 治療 HCV；活動性血管炎用 rituximab；類固醇}}

## IgA vasculitis（Henoch-Schönlein purpura）

### 重點
- {{p|四大表現：**palpable purpura**（臀部與下肢）、關節痛、腸胃症狀（腹部絞痛、血便等）、**腎絲球腎炎**（蛋白尿、血尿）}}
- 小孩較多，成人也可能
- {{p|皮膚切片：**leukocytoclastic vasculitis 合併 IgA 與 C3 沉積**}}
- 檢驗：白血球輕微高、**血小板正常**、偶有嗜酸性球增多、**補體正常**、約一半 IgA 偏高
- 臨床診斷；大部分不需治療即可恢復，某些情況可考慮類固醇

# 結晶性關節炎

## Gout 痛風

### 流行病學
- {{r|好發於中老年男性、停經後婦女}}（考109）
- {{r|**台灣原住民盛行率偏高（> 10%）**}}（考109）
- {{o|高尿酸血症只有約 1/10 會發展成痛風}}
- 正常人每天產生約 750 mg 尿酸，500 mg 由腎臟排出，其餘由大腸排出

### 高尿酸血症原因
- 攝取過多嘌呤、內源性產生增加、腎臟排泄受阻
- {{r|藥物與食物：**thiazide、furosemide、低劑量 aspirin（< 2 g/day）、抗結核藥（pyrazinamide、ethambutol）、cyclosporine**、啤酒、烈酒、果糖}}（考109、112）

### 症狀與診斷
- 來得快去得快（{{o|病程一般不超過 7 天}}）
- {{p|好發下肢，典型為 **1st MTP**、腳踝、膝蓋}}
- 2015 ACR criteria：{{o|UA < 4 mg/dL}} 或關節液沒看到結晶要**扣分**

### 治療（考108）
- {{r|**UA > 7 加上以下任一**需降尿酸治療：痛風石、一年 ≥ 2 次發作、尿路結石}}（考109）
- {{r|急性發作：**NSAID、colchicine、類固醇**}}（考113）
- 開始降尿酸藥物時搭配 colchicine {{o|3～6 個月以上}}
- {{r|UA 目標：}}{{o|**無痛風石 < 6 mg/dL；有痛風石 < 5 mg/dL**}}（2020 ACR 指引：都是 < 6）（考106、112、113）
- {{b|**Febuxostat**}}：小心肝炎；2018 NEJM 顯示 CV mortality 似乎比 allopurinol 高；{{p|不能和 azathioprine 併用}}
- {{b|**Benzbromarone**}}：促進尿酸排泄；{{p|腎結石禁用、腎功能不好不能用}}
- {{r|**Allopurinol**：可驗 **HLA-B*5801**}}（考106）；{{p|不能和 azathioprine 併用}}
- 2020 ACR 指引：第一次發作就可考慮降尿酸藥（108 年考古還是舊觀念）

## CPPD（假性痛風）

### 重點
- 好發膝蓋、手腕、肩膀、腳踝
- 相關因子：{{r|**年紀大**}}（考109）、**primary hyperparathyroidism、低血磷、低血鎂、hemochromatosis**、甲狀腺功能低下、Gitelman syndrome、thiazide 與 loop 利尿劑（可能還有 PPI）
- {{p|影像：關節 X 光軟骨中間一條白線（**chondrocalcinosis**）→ CPPD}}
- 強調超音波診斷
- {{b|治療：NSAID、類固醇注射；頻繁發作可用低劑量 colchicine 預防}}

# 其他風濕疾病

## IgG4-related disease（考105、109、110、113、114）

### 重點
- {{p|**像腫瘤的病灶，但是良性**}}
- 可能有過敏表現：濕疹、氣喘、鼻息肉、鼻竇炎、輕度嗜酸性球增多
- 好發：**唾液腺（顎下腺、腮腺）、胰臟、膽道、淋巴結、主動脈**
- {{p|**Retroperitoneal fibrosis → hydronephrosis**}}
- 機轉可能與 CD4+ cytotoxic T cell 有關
- {{r|**血清 IgG4 ≥ 135 mg/dL** 可參考但不是診斷依據（**約 30% 病人 IgG4 正常**）}}（考114）
- {{r|病理：**IgG4+ 漿細胞浸潤（> 10/HPF、IgG4／IgG > 40%）**、**storiform fibrosis**、**obliterative phlebitis**、輕中度嗜酸性球浸潤}}（考106、109、112、114）
- {{r|治療：**類固醇為主**、DMARD、rituximab}}（考111）；inebilizumab（anti-CD19，2025 NEJM）
- 臨床改善後血清 IgG4 仍可能偏高

### 考題重點
- {{r|腹膜後腫塊懷疑 IgG4-RD，正確：**組織切片 IgG4+／IgG+ 漿細胞比例 > 40%**}}（考114）
- {{r|眼乾口乾、眼皮浮腫、兩側腮腺與頸部淋巴腺腫，ANA 與 SSA／SSB 陰性、amylase 高 → **IgG4-related disease**}}（考114）

## Sarcoidosis 類肉瘤病

### 重點
- **Non-caseating granulomas**；需排除 TB、黴菌、淋巴癌
- 通常侵犯兩個以上器官：{{o|肺（90%）> 皮膚 > 眼睛}}
- 可能與 *Propionibacterium acnes* 有關
- 症狀：無症狀的**兩側肺門淋巴結腫大**、uveitis、皮疹
- 檢驗：ACE 可能偏高；{{o|**BAL：lymphocytosis > 2 倍正常上限 + CD4／CD8 > 3.5**}} → 高度懷疑；**高血鈣**
- 診斷多需切片
- {{b|治療：NSAID、類固醇、DMARD、infliximab}}

## Relapsing polychondritis

### 重點
- 侵犯**耳朵、鼻子、喉頭的軟骨**與眼睛
- {{g|**MAGIC syndrome**：Mouth And Genital ulcers with Inflamed Cartilage（要和 Behçet 區別）}}
- {{b|治療：類固醇、NSAID、DMARD、cyclophosphamide、IL-6 inhibitor}}

## Adult onset Still's disease（AOSD）（考107、110）

### 重點
- {{p|**一般要先排除癌症、感染與其他免疫疾病**}}
- 症狀：
  - {{p|**發燒：一天 1～2 個高峰**}}
  - {{p|**Salmon-pink rash：發燒時出現、燒退消失**}}
  - 喉嚨痛、肝腫大、淋巴結腫大
- 檢查：ESR、CRP 高；{{p|**ferritin 通常很高**}}；leukocytosis；肝指數高；**RF／ANA 陰性**
- {{b|治療：NSAID、類固醇、MTX、azathioprine；anti-IL-1（**canakinumab**，第一個 FDA 核准治療 AOSD 的生物製劑）、anti-IL-6、anti-TNF}}

## Behçet's syndrome

### 重點
- 「絲路病」
- 反覆疼痛的口腔潰瘍、生殖器潰瘍（男性陰囊、女性大陰唇）
- 皮膚像青春痘的病灶
- {{r|眼睛：**panuveitis（常見雙側）**}}（考113）；{{g|其他常見 uveitis 的免疫病：PsA、AS、sarcoidosis}}
- Erythema nodosum（panniculitis，下肢常見，常被誤認為 cellulitis）
- 血管炎、血栓、動脈瘤；CNS 侵犯
- {{p|**Pathergy test**：無菌針頭刺入前臂真皮，24～48 小時後出現 > 2 mm 紅斑結節或膿疱為陽性}}
- **HLA-B*51**（{{o|20% 正常人也有}}）
- 診斷：ISG criteria（{{o|敏感度約 95%、特異度約 96%}}）：{{o|口腔潰瘍（一年 ≥ 3 次）}} + 以下 2 項：反覆生殖器潰瘍、皮膚病灶、眼睛病灶、pathergy 陽性
- {{b|治療：類固醇、colchicine、azathioprine、anti-TNF、cyclophosphamide（嚴重血管炎或 CNS）、抗凝血劑；**apremilast** 治療口腔潰瘍（2019 NEJM）}}

# 過敏與免疫缺乏

## Urticaria and angioedema（考106）

### 重點
- Urticaria 包含 wheals 與 angioedema
- {{o|Wheals：表淺真皮、< 24 小時、癢}}
- Angioedema：深層真皮與皮下水腫，**痛 > 癢**，有時要幾天才消
- {{o|慢性：> 6 週}}
- Chronic spontaneous urticaria（CSU）：
  - Type I autoallergic：與 IgE 有關
  - Type IIb autoimmune：total IgE 偏低、IgG anti-TPO 偏高，**對抗組織胺與 omalizumab 反應較差**

### 治療
- {{b|一線：第二代抗組織胺（最多 **4 倍**劑量）}}
- {{b|二線：**omalizumab**（Xolair，anti-IgE）}}
- {{b|三線：cyclosporine}}
- 新藥：dupilumab（anti-IL-4Rα）、remibrutinib（BTK inhibitor），指引建議抗組織胺失敗後可當二線
- {{p|**外用類固醇沒效**}}
- {{r|避免長期全身性類固醇；全身性類固醇用於 pressure urticaria、**vasculitic urticaria（尤其嗜酸性球明顯）**、idiopathic angioedema、傳統治療反應差的慢性蕁麻疹}}（考113、114）
- {{b|遺傳性血管水腫（HAE）：**icatibant**（bradykinin B2 receptor antagonist）、sebetralstat（口服 plasma kallikrein inhibitor，2024 NEJM）、donidalorsen（2024 NEJM）}}

### 考題重點
- {{r|25 歲女性蕁麻疹 10 天、**eosinophilia** → 最有效：**systemic corticosteroids**}}（考114）

## 免疫缺乏（考105、113）

### 重點
- {{r|**Anti-IFN-γ 自體抗體**：88% 有多重伺機性感染的亞洲成人可偵測到 → 類似晚期 HIV 的成人型免疫缺乏}}（2012 NEJM）（考113）
- {{r|**Anti-IL-23 中和抗體**：與嚴重、持續的伺機性感染（分枝桿菌、細菌、黴菌）相關}}（2024 NEJM）（考113）

### 原發性免疫缺乏
| 疾病 | 缺陷 | 表現 |
|---|---|---|
| X-linked (Bruton) agammaglobulinemia | BTK 基因 → 沒有 B cell | 6 個月後反覆細菌與腸病毒感染；周邊血沒有 B cell、各類 Ig 都低；淋巴結扁桃腺缺如；禁打活性疫苗 |
| Selective IgA deficiency | 不明；**最常見**的原發性免疫缺乏 | 多數無症狀；呼吸道與腸胃感染、自體免疫、過敏；{{p|輸含 IgA 血品可能過敏性休克}} |
| Common variable immunodeficiency | B cell 分化缺陷 | 多在 2 歲後；反覆感染、自體免疫、淋巴瘤 |
| DiGeorge syndrome | 22q11 缺失 → 胸腺與副甲狀腺發育不全 | 低血鈣抽搐、反覆病毒黴菌感染、心臟畸形；CXR 沒有胸腺影 |
| Hyper-IgE（Job）syndrome | STAT3 突變 → Th17 缺乏 | **FATED**：粗臉、冷膿瘍、乳牙滯留、IgE 高、濕疹 |
| SCID | 多種（最常見 IL-2R γ 鏈，X-linked） | 生長遲滯、慢性腹瀉、鵝口瘡、各類感染；骨髓移植可治癒 |
| Ataxia-telangiectasia | ATM 基因 | 小腦失調、微血管擴張、IgA 缺乏；AFP 高；淋巴瘤與白血病風險 |
| Hyper-IgM syndrome | CD40L 缺陷（X-linked） | 嚴重化膿性感染、肺囊蟲、Cryptosporidium；IgM 正常或高、IgG／IgA／IgE 低 |
| Wiskott-Aldrich syndrome | WAS 基因（X-linked） | **WATER**：血小板少且小、濕疹、反覆感染；IgE、IgA 高 |
| Leukocyte adhesion deficiency | LFA-1（CD18） | 反覆皮膚黏膜感染、**沒有膿**、傷口癒合慢、**臍帶延遲脫落（> 30 天）**；血中嗜中性球高 |
| Chédiak-Higashi syndrome | LYST 基因 | **PLAIN**：進行性神經退化、淋巴組織球增生、部分白化症、反覆感染、周邊神經病變；**巨大顆粒** |
| Chronic granulomatous disease | NADPH oxidase | {{p|**catalase 陽性**菌感染}}；DHR 流式檢查異常、NBT 不變藍 |

## 過敏性鼻炎

### 重點
- 症狀：流鼻水、鼻塞、鼻涕倒流、鼻咽癢、打噴嚏
- 臨床診斷；可做 skin test 或血清 IgE
- {{r|治療：**避免過敏原、類固醇鼻噴劑**為主}}（考103、112）

## COVID-19 疫苗引起的血栓（VITT）（考110、113）

### 重點
- {{p|腺病毒疫苗相關的 **anti-PF4 抗體**}}
- 確定診斷（5 項都要符合）：
  - {{o|打 COVID 疫苗後 **4～42 天**}}發病
  - 任何靜脈或動脈血栓（常在**腦部或腹部**）
  - {{o|血小板 < 150 × 10⁹/L}}
  - PF4 抗體陽性
  - {{o|D-dimer > 4 倍正常上限}}
- {{b|治療：**IVIG**、**非 heparin 類**抗凝血劑}}
