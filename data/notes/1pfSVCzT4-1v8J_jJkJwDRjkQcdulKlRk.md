# 甲狀腺

## 甲狀腺功能判讀

### 基本觀念
- TRH → TSH → T4/T3，fT4、fT3 負回饋抑制下視丘與腦下垂體
- {{p|**TSH 是最重要的單一數據**}}：T4、T3 小幅變化就會讓 TSH 大幅變動
- {{o|TSH **4～10** + fT4 正常 → 觀察}}；{{o|TSH **> 10** + fT4 正常 → 給 levothyroxine}}

### T4 與 T3
| | T4 | T3 |
|---|---|---|
| 來源 | 甲狀腺分泌 | {{o|**80% 由周邊 T4 轉換**}} |
| 游離比例 | {{o|0.03%}} | {{o|0.3%}} |
| 角色 | 前驅荷爾蒙 | **活性荷爾蒙** |
| 半衰期 | {{o|**5～7 天**}} | {{o|**1.5 天**}} |

- T3 與蛋白結合力較低 → {{p|代謝活性約**強 3 倍**、半衰期較短}}
- 結合蛋白：TBG 最多，其次 albumin、transthyretin

### 判讀陷阱
- 生理變化：**hCG**（懷孕）、老化
- 正在補充 levothyroxine、癌症的 TSH 抑制治療
- 藥物造成甲狀腺失調：**amiodarone、immune checkpoint inhibitor、TKI**
- {{p|**抑制 TSH 的藥物：dopamine、glucocorticoids、somatostatin**}}（加上 T3 本身）
- 檢驗干擾：heparin

### 考題重點
- {{r|**不會**抑制 TSH 分泌的：**insulin**}}（考114，答 A）

## 甲狀腺毒症（thyrotoxicosis）

### Graves' disease 定義
- 四項中符合兩項：(1) 甲狀腺機能亢進 (2) 瀰漫性甲狀腺腫 (3) **甲狀腺眼病變或脛前黏液水腫** (4) **TRAb 或 TSI 陽性**
- {{p|若只有 (1) + (2)，**(4) 必須陽性**}}
- {{g|脛前黏液水腫是**不可壓凹**（non-pitting）}}
- 眼病變：上眼瞼後縮、lid lag、突眼；眼窩 CT 可見外眼肌腫大

![Graves' disease 治療選項比較：抗甲狀腺藥物、放射性碘、手術](img/1pfSVCzT4-1v8J_jJkJwDRjkQcdulKlRk/p008.webp)

### 鑑別診斷
- {{p|**金標準：I-131 uptake & scan**}}（正常攝取 {{o|15～40%}}）
- 攝取**正常或增加**：Graves、hCG 相關、toxic nodule、toxic MNG
- 攝取**消失**：甲狀腺炎、**外源性甲狀腺素**、碘、struma ovarii、轉移
- {{g|**外源性甲狀腺素（例如兵役體檢前吃藥）→ 查 thyroglobulin，會偏低**}}；其他甲狀腺毒症 thyroglobulin 都上升

![甲狀腺毒症鑑別：放射性碘攝取與掃描](img/1pfSVCzT4-1v8J_jJkJwDRjkQcdulKlRk/p009.webp)

### 甲狀腺炎
| | 亞急性甲狀腺炎 | 急性（化膿性）甲狀腺炎 | Hashimoto |
|---|---|---|---|
| 病因 | 病毒感染或感染後發炎，{{o|發病前約 1 週可有 URI}} | **細菌感染**，罕見但可能致命 | 自體免疫 |
| 表現 | 發燒、**疼痛、石頭般硬**的甲狀腺 | 急性疼痛、壓痛腫脹、發燒、白血球上升 | 甲狀腺低下、瀰漫性甲狀腺腫 |
| 甲狀腺功能 | TSH↓、**ESR↑**、{{p|**碘攝取低**}} | **通常正常** | 亢進 → 正常 → 低下 |
| 關鍵 | | 誘因：**pyriform sinus fistula**；FNA 送培養 | {{o|aTG 或 aTPO 陽性、TRAb 陰性}} |
| 治療 | {{b|**Inderal、NSAIDs** 或 prednisolone}} {{o|40～60 mg}}；{{p|**不用抗甲狀腺藥物**}} | {{b|廣效抗生素（要涵蓋**厭氧菌**）}} | 低下時給 {{b|levothyroxine}} |

### 甲狀腺毒性週期性麻痺（TPP）
- {{g|**Rule of 2**}}：亞洲人 {{o|2%}}（西方 0.2%）、{{o|**男：女 = 20：1**}}、{{o|20～40 歲}}、{{o|血鉀約 2 mmol/L}}、{{o|尿鉀 < 20}}
- 機轉：K channel 突變 → {{p|**細胞內轉移，不是從尿流失**}}
- 常在大餐、壓力後發作

### 考題重點
- {{r|**不是** Graves 特徵的：**脛前可壓凹水腫（pitting edema）**}}（考古，年份未標）
- {{r|最不適當的：**單測 TSH 就能鑑別腦下垂體造成的甲狀腺異常**}}（考古，年份未標；中樞性要看 fT4）
- {{r|頸部疼痛從左側轉到右側、ESR 上升 → **亞急性甲狀腺炎，可給 NSAID**}}（考111，答 C）
- {{r|**甲狀腺亢進、低下或正常的人都可能有甲狀腺相關眼病變**}}（考114，答 B）；錯誤選項：TPP 最常見於西方女性、最常見心血管表現是 AF（應為**竇性心搏過速**）、TSI 濃度與荷爾蒙濃度直接相關
- {{r|年輕男性大餐後下肢無力、上肢正常 → 必要檢查 **free T4、hsTSH + Na、K**}}（考101，答 A）

## 甲狀腺風暴（thyroid storm）

### 診斷
- 罕見但致命，{{o|死亡率 5～10%}}
- 甲狀腺毒症是高代謝狀態；**風暴是失代償的多器官功能障礙**
- {{p|**臨床診斷：嚴重度與甲狀腺功能高低無關**}}
- {{o|**Burch-Wartofsky Point Scale：< 25 不太可能、25～45 即將發生、> 45 極可能**}}

### 一線治療
- {{b|**PTU 200 mg q4～6h**}}：阻斷合成 + {{p|抑制周邊 T4 → T3}}，{{o|1 小時起效}}；風暴時{{p|**優先選 PTU**}}
- {{b|**Propranolol 20～80 mg PO q4～6h**}}：也減少 T4 → T3
- {{b|**Hydrocortisone 100 mg q8h**}}（前 24～36 小時）：也減少 T4 → T3
- {{b|**Lugol solution 5 滴 q6h**}}，{{p|**PTU 給完 1 小時後才給**}}；利用 acute Wolff-Chaikoff effect，{{o|7～14 天會 escape}}

### 抗甲狀腺藥物
- Thionamides：PTU、MMI、CMZ（{{p|CMZ 是 MMI 的前驅藥}}）；一般**優先 MMI**，風暴用 PTU
- PTU 抑制 TPO，並抑制周邊 deiodinase（D1）

### 考題重點
- {{r|發燒、心跳 175 不規則、心衰竭的甲狀腺亢進 → 正確：**PTU 比 MMI 好、Digoxin 比 Amiodarone 適當**}}（考102，答 C）；此時仍應給糖皮質素（壓力下 cortisol 20 不代表足夠），且{{p|不能排除甲狀腺風暴}}

## 碘與 amiodarone

### Wolff-Chaikoff effect
- 大量碘 → **暫時抑制 TPO** → 合成減少；之後 NIS 表現下降、碘進入減少 → {{p|恢復合成（escape）}}
- 碘缺乏：TSH 上升 → 甲狀腺肥大增生（先瀰漫，後結節）
- 大劑量碘也可能**加重**甲狀腺亢進（Jod-Basedow）

### Amiodarone 引起的甲狀腺失調
| | 甲狀腺低下（AIH） | 甲狀腺亢進（AIT） |
|---|---|---|
| 機轉 | {{p|**無法 escape Wolff-Chaikoff**}}，原有 Hashimoto | {{p|**Jod-Basedow**}}（type 1）或 甲狀腺炎（type 2） |
| 地區 | {{g|**碘充足地區較多**}} | {{g|**碘缺乏地區較多**}} |
| 處置 | {{b|補 Eltroxin，**可繼續 amiodarone**}} | {{b|考慮停 amiodarone}} |

### 考題重點
- {{r|Amiodarone 正確：**200 mg 可使血尿碘上升 40 倍、碘充足地區較易低下、低下時不需停藥**}}（考108，答 C）；{{p|停藥後碘含量要好幾個月才會下降}}

## 甲狀腺低下

### 病因
- 原發性：**Hashimoto**（查 aTG、aTPO）、甲狀腺切除或頸部放療後、中重度碘缺乏
- 藥物：{{b|**amiodarone、lithium、免疫治療、標靶藥物**}}
- 次發性（中樞性）：{{p|**要查 cortisol/ACTH，排除全腦下垂體低下**}}

### Myxedema coma
- 極度甲狀腺低下，{{o|死亡率 5～30%}}；通常有長期低下病史
- 臨床診斷：**呼吸抑制 + CO₂ 滯留 → 昏迷**、{{o|**低體溫 24～32°C**}}、低血壓（心搏過緩）、**低血鈉**、皮膚乾冷、**non-pitting 水腫**
- 誘因：感染、疾病、外傷、抑制中樞的藥物

### Non-thyroidal illness（sick euthyroid）
- 重症病人常見；{{p|需要 **TT4、fT4、T3、TSH 全套**才能鑑別}}
- 周邊 D1↓ → {{o|**T3↓（< 40 ng/dL）、rT3↑**}}、TSH↓
- {{p|**治療原本疾病，補 levothyroxine 沒有好處**}}

### 考題重點
- {{r|最正確：**亞臨床低下多無症狀，每年追蹤；想懷孕或 TSH > 10 持續 3 個月以上才給藥**}}（考113，答 E）；Hashimoto 的甲狀腺通常**硬、不規則**；不建議多攝取碘；不建議用 T3 治療

## 懷孕與甲狀腺

### 生理變化
- {{p|**hCG 與 TSH 次單位相同 → fT4 上升**}}；雌激素↑ → TBG↑ → 總 T4、T3 上升
- 要用**懷孕期別專屬**的參考值
- 甲狀腺亢進：流產、周產期死亡、妊娠高血壓、心衰竭、風暴、IUGR；{{p|亞臨床亢進沒有影響}}
- 甲狀腺低下：早產、流產、妊娠高血壓、{{p|**神經認知發展受損、IQ 降低**}}

### 抗甲狀腺藥物選擇
- {{b|**第一孕期 PTU 優於 MMI/CMZ**}}：先天缺陷絕對風險 {{o|3%（PTU）vs 5%（MMI/CMZ）}}，PTU 缺陷較輕微
- {{g|MMI 缺陷：**aplasia cutis**、後鼻孔閉鎖、臍膨出、食道閉鎖}}
- 懷孕後可停藥的條件：{{o|治療 > 6 個月}}、TSH 正常、{{o|MMI < 10 mg（PTU < 200 mg）}}、無眼病變或甲狀腺腫、{{o|TRAb < 3 倍上限}}
- 用**最低劑量單一藥物**；{{p|**目標 fT4 維持在上限或略高**}}（胎兒比母親敏感）
- {{p|**避免 block-and-replace**}}：ATD 容易通過胎盤、LT4 不易通過
- 懷孕後期可減量

### 考題重點
- {{r|最正確：(1) ATD 可通過胎盤 (4) TSH 低 fT4 正常要測 fT3 (5) fT4 高 TSH 正常或高 → 考慮 TSHoma 或甲狀腺荷爾蒙阻抗}}（考111，答 D）；{{p|哺乳期可用 ATD；PTU 有放射保護作用，放射性碘前也要停}}
- {{r|懷孕與甲狀腺正確：(1) TSI 可過胎盤造成胎兒甲狀腺毒症 (3) 放射性碘後 6 個月可受孕、懷孕哺乳禁用 (4) 胎兒甲狀腺毒症：IUGR、心跳 > 160、骨齡超前、甲狀腺腫}}（考111，答 D）

## 甲狀腺結節

### 評估
- 重要性：功能（toxic nodule）、壓迫症狀、{{o|**惡性 7～15%**}}
- 四要素：病史與理學檢查、**TSH**、**超音波**、需要時 **FNA**
- {{p|**TSH 低 → 先做核醫掃描**}}：hot nodule 幾乎都是良性；cold nodule 惡性 {{o|5～15%}}
- 高風險病史：放射線暴露、MEN2 家族史

### 超音波特徵
| 特徵 | 良性 | 惡性 |
|---|---|---|
| 成分 | 囊性 | 實心 |
| 回音 | 高、等回音 | **明顯低回音** |
| 形狀 | wider than tall | {{p|**taller than wide**}} |
| 邊緣 | 平滑 | 不規則 |
| 鈣化 | 無 | {{p|**點狀鈣化（PEFs）**}}、粗鈣化 |

![ATA 2015 超音波型態與 ACR TI-RADS 的 FNA 門檻](img/1pfSVCzT4-1v8J_jJkJwDRjkQcdulKlRk/p045.webp)

- ACR TI-RADS：{{o|TR5 ≥ 1 cm、TR4 ≥ 1.5 cm、TR3 ≥ 2.5 cm 做 FNA}}

### 2023 Bethesda 分類
| 分類 | 惡性風險 | 處置 |
|---|---|---|
| I 檢體不足 | {{o|13%}} | 重做 FNA |
| II 良性 | {{o|4%}} | 追蹤 |
| III AUS | {{o|22%}} | 重做 FNA、分子檢測 |
| IV 濾泡性腫瘤 | {{o|**30%**}} | 分子檢測、**lobectomy** |
| V 疑似惡性 | {{o|74%}} | 手術 |
| VI 惡性 | {{o|97%}} | 手術 |

### 考題重點
- {{r|右側 2 cm 結節、FNA 為 follicular neoplasm、**TSH 0.1** → **I-131 uptake & scan**}}（考104，答 A）；{{p|TSH 被抑制表示可能是 hot nodule（幾乎良性），先掃描；若 TSH 正常才直接開刀}}
- {{r|**taller-than-wide 結節惡性風險較高**}}（考112，答 A）；濾泡瘤惡性約 30%、3.5 cm 為 T2、低風險不一定要放射性碘、淋巴癌以化放療為主

## 甲狀腺癌

### 分化型甲狀腺癌
| | 乳突癌 | 濾泡癌 |
|---|---|---|
| 比例 | {{o|**80%**}} | {{o|5～10%}} |
| 轉移途徑 | **淋巴** | **血行** |
| 轉移部位 | 肺 | 骨、肺、腦、肝 |
| 診斷 | {{p|**FNA 的細胞核特徵**}} | {{p|**病理的包膜侵犯**}}（FNA 無法區分良惡性） |

- Hürthle cell tumor：濾泡癌變異型，{{o|只有約 5% 吸收放射性碘}}

### 治療
- {{b|**≤ 2 cm、無甲狀腺外侵犯、N0M0 → lobectomy**}}；低風險 2～4 cm 也可 lobectomy
- 術後：{{b|levothyroxine TSH 抑制（目標低正常）}}；{{b|中高風險才給 I-131}}
- 長期追蹤：頸部超音波 + **thyroglobulin**；Tg 上升 → I-131；{{p|**放射性碘抗性 → PET 與標靶治療**}}

### 髓質癌（MTC）
- {{o|占甲狀腺癌 3～5%}}；來自神經嵴的**濾泡旁 C 細胞**，分泌 {{p|**calcitonin 與 CEA**}}（術前診斷與追蹤的 tumor marker）
- {{o|成人 75% 偶發性}}；兒童多為遺傳；**RET** 突變
- MEN2 要查**副甲狀腺亢進、嗜鉻細胞瘤**
- {{b|**手術是唯一根治方法**}}；晚期 RET 突變：{{b|**selpercatinib**}}；{{p|放射性碘**無效**}}
- {{p|**MEN2B 的 MTC 比 MEN2A 更具侵襲性**}}
- 預防性甲狀腺切除時機（依 RET codon）：{{o|**918（MEN2B）→ < 6 個月**}}、{{o|**634 等高風險 → < 5 歲**}}、其他 → 5～10 歲（calcitonin 上升就立刻開）
- {{g|MEN2A 85% 是 codon 634；MEN2B 95% 是 codon 918}}

### 考題重點
- {{r|PTC 全切 + 多次 I-131 後 Tg 正常但 **anti-Tg 抗體高**、最近掃描無攝取 → **安排 PET**}}（考108，答 C）；抗 Tg 抗體會干擾 Tg 判讀
- {{r|MTC 正確：**MEN2B 比 MEN2A 侵襲性高**}}（考113，答 D）；錯誤選項：點狀鈣化風險較低、MTC 對放射性碘效果好、TSH 維持上限
- {{r|MTC 正確：**約占 5～10%**、**約 20% 有家族史**、**可能分泌異位 ACTH 造成 Cushing**}}（考106，答 B）；MEN2 是**腎上腺髓質**（嗜鉻細胞瘤）不是皮質；帶 RET 突變要在**兒童期**切除
- {{r|腎結石、PTH 高、高血鈣、sestamibi **左上左下兩處 hot spot** + 甲狀腺囊腫 → **多發性內分泌腫瘤（MEN）**}}（考111，答 D）
- {{r|MTC 正確：**calcitonin 可當術前診斷與術後追蹤的 tumor marker**}}（考110，答 C）
- {{r|最正確：**T1N0M0 分化癌給放射性碘不會影響再發率或存活率**}}（考114，答 C）；{{p|急性甲狀腺炎要等**急性期過後**才找 pyriform sinus fistula}}；懷孕的亞臨床低下**建議**治療；亞急性甲狀腺炎好發**女性**

# 副甲狀腺與骨骼礦物質

## 鈣的調控

### PTH 與維生素 D
- {{p|**PTH 淨效果：升鈣、降磷**}}：增加骨吸收、腎臟吸收鈣且排磷、活化 1α-hydroxylase（25-OH-D → 1,25-(OH)₂D）
- 維生素 D：促進腸道吸收鈣與磷
- {{p|**診斷維生素 D 缺乏：測 25-OH-D**}}
- {{b|活化型 D3（calcitriol）用於腎衰竭、副甲狀腺低下}}
- FGF23：促使腎臟排磷並降低 1,25-(OH)₂D

## 高血鈣

![高血鈣診斷流程與 PTHrP 機轉](img/1pfSVCzT4-1v8J_jJkJwDRjkQcdulKlRk/p063.webp)

### PTH 依賴型
- **原發性副甲狀腺亢進**
- **FHH**：{{p|**calcium-sensing receptor 突變，體染色體顯性**}}；輕度高血鈣 + **低尿鈣**，PTH 正常偏高
- **鋰鹽**：改變 PTH 抑制的 set point；{{p|**停藥後可恢復**}}
- 三級副甲狀腺亢進、抗 CaSR 自體抗體

### PTH 非依賴型
- 惡性腫瘤：{{p|**PTHrP**（**鱗狀細胞癌**、腎細胞癌、乳癌）}}、骨轉移
- 維生素 D 中毒；**1α-hydroxylase 活性增加**（sarcoidosis、TB、黴菌、淋巴瘤）
- Milk-alkali syndrome：高血鈣 + 鹼中毒 + 腎功能受損
- 不動（immobilization）
- 內分泌：**甲狀腺亢進**（高代謝轉換）、**腎上腺功能不足**（血液濃縮）、嗜鉻細胞瘤（PTHrP）、VIPoma
- {{g|**維生素 A 中毒**也會高血鈣}}

### 原發性副甲狀腺亢進
- 經典：{{g|**bones and stones**}}——頭骨 salt-and-pepper、指骨骨膜下吸收、brown tumor、腎結石
- 病因：{{o|**adenoma 80～85%、增生 10～15%、癌 < 1%**}}
- 定位：副甲狀腺超音波、{{b|**Tc99m sestamibi**}}（晚期相仍殘留）
- 無症狀病人開刀條件（2013）：{{o|**血鈣超過上限 > 1 mg/dL**}}、{{o|**T-score < −2.5 或椎體骨折**}}、{{o|**Ccr < 60**}}、結石、{{o|尿鈣 > 400 mg/d}}、{{o|**年齡 < 50 歲**}}

### 藥物治療
- 高血鈣危象：大量輸液、{{b|calcitonin（最快，但會 **tachyphylaxis**）}}、{{b|bisphosphonate、denosumab}}
- {{b|**Cinacalcet（calcimimetic）**}}：活化 CaSR → PTH 下降；{{p|**不會增加骨密度**}}
- CaSR 功能增強 → ADH（體染色體顯性低血鈣）；功能喪失 → FHH、新生兒嚴重副甲狀腺亢進

### 考題重點
- {{r|原發性副甲狀腺亢進**最不常見**的表徵：**手麻與抽筋**}}（考古，年份未標；那是低血鈣）
- {{r|**不正確**：**Calcimimetics 可增加骨密度**}}（考110，答 D）
- {{r|可能造成高血鈣：(1) 副甲狀腺癌、鋰鹽、FHH (2) **24-hydroxylase 缺乏** (5) 惡性腫瘤轉移或體液因子}}（考111，答 E）；{{p|是維生素 A **過量**、甲狀腺**亢進**才會高血鈣}}
- {{r|最正確：**calcitonin 抑制蝕骨細胞；腦、腸胃、免疫系統都有其受體**}}（考113，答 E）；最常見病因是副甲狀腺亢進與癌症（約 90%），但維生素 D **缺乏**不會高血鈣；開刀條件是 **< 50 歲**、Ccr **< 60**
- {{r|最正確：**鱗狀細胞癌較常引起高血鈣**（小細胞癌、腺癌少見）}}（考114，答 C）；{{p|FHH 是**體染色體顯性**、鋰鹽高血鈣停藥可恢復、副甲狀腺癌存活期長、calcitonin 很少造成嚴重低血鈣}}

# 腎上腺

## 原發性高醛固酮症（PA）

### 定義與篩檢
- {{p|醛固酮分泌相對鈉狀態**不適當地高**，且**鹽負荷無法抑制**}}
- 篩檢：**aldosterone-renin ratio（ARR）**；先矯正低血鉀、{{p|**停 MRA（spironolactone）至少 4 週**}}
- 表現：高血壓、低血鉀、代謝性鹼中毒；{{p|增加**糖尿病與骨質疏鬆**風險}}

### 藥物與狀況對 ARR 的影響
| 因素 | Aldosterone | Renin | ARR |
|---|---|---|---|
| {{b|**β-blocker**}} | ↓ | ↓↓ | {{p|**↑（偽陽性）**}} |
| {{b|DHP CCB}} | →↓ | ↑ | ↓ |
| {{b|**ACEI / ARB**}} | ↓ | ↑ | {{p|**↓（偽陰性）**}} |
| {{b|Renin inhibitor}} | ↓ | ↓↓（PRA） | ↑ |
| {{b|K-sparing diuretics}} | ↑ | ↑↑ | ↓ |
| {{b|K-wasting diuretics}} | →↑ | ↑↑ | ↓ |
| {{b|Clonidine、α-methyldopa}} | ↓ | ↓↓ | ↑ |
| {{b|NSAIDs}} | ↓ | ↓↓ | ↑ |
| 低血鉀 | ↓ | →↑ | ↓ |
| 高齡、CKD | ↓ / → | ↓↓ / ↓ | ↑ |
| 懷孕 | ↑ | ↑↑ | ↓ |

- {{g|**α-blocker 幾乎不影響**，是篩檢期間可換用的藥}}

### 確診與分側
- 確認試驗：{{b|saline infusion test}}（{{o|4 小時 2 L；醛固酮 **< 5 ng/dL** 排除，10 ng/dL 不能排除}}）、captopril suppression test
- 病因：{{o|**雙側增生約 60%、APA 約 40%**}}（近年多為雙側）
- **Adrenal vein sampling** Selectivity index（cortisol 腎上腺/周邊）：{{o|有 cosyntropin > 5：1；沒有 > 3：1（台灣 > 2：1）}}
- AVS {{p|**Lateralization index > 4：1 → 單側**}}；{{o|< 3：1 雙側（台灣非刺激下 ≥ 2 即單側）}}
- 治療：單側 → 腎上腺切除；雙側 → {{b|MRA（spironolactone）或鈉通道阻斷劑（amiloride）}}
- {{g|**GRA**：醛固酮由 **ACTH** 調控（不是 renin），家族遺傳、早發高血壓與中風}}；{{b|用**低劑量糖皮質素**}}，必要時加 MRA

### 考題重點
- {{r|會讓 ARR **上升**的降壓藥：**β-blocker**}}（考古，年份未標）
- {{r|使 renin↑、aldosterone↓、ARR↓ 的：**ACE inhibitor**}}（考古，年份未標）
- {{r|1.5 cm 腎上腺瘤、服用 amlodipine + ramipril、下午 4 點抽血 aldosterone 6.9、PRA < 0.6 → **重檢早上 8 點 aldosterone 與 PRA**}}（考103，答 B）；{{p|服 ACEI 下 renin 仍被抑制，高度懷疑 PA}}
- {{r|PA 正確：**AVS 單側 aldosterone/cortisol 比值至少為對側 4 倍**}}（考107，答 E）
- {{r|正確：(1) β-blocker 使 renin 下降、ARR 上升 (2) α-blocker 不影響}}（考108，答 C）
- {{r|**不正確**：**PA 可減少骨質疏鬆風險**}}（考111，答 A）
- {{r|最正確：**GRA 以低劑量 dexamethasone 控制血壓，必要時加 MRA**}}（考古，題號標 11100，答 E）
- {{r|最正確：**GRA 的醛固酮受 ACTH 而非 renin 調控**}}（考113，答 B）；只有約 {{o|9～37%}} 有低血鉀；β-blocker 使 ARR 上升，所以沒停藥而 ARR 低，較可排除
- {{r|正確：(2) β-blocker 使 ARR 上升，結果不確定時停 2 週再測 (5) 雙側小結節增生用 MRA 或鈉通道阻斷劑}}（考112，答 D）；spironolactone 要停 **4 週**；食鹽水試驗 10 ng/dL 不能排除；年齡界線是 **35 歲**

## Cushing 症候群

### 生理
- {{p|**cortisol 早上最高、半夜最低**}}：懷疑缺乏 → 測**早上**；懷疑過多 → 測**半夜**

### 病因
- {{p|**最常見：醫源性**}}；自發性 {{o|1～2/100,000}}
- ACTH 依賴：{{o|**Cushing's disease（腦下垂體）75%**}}、{{o|**異位 ACTH 15%**}}
- ACTH 非依賴：{{o|**腎上腺腫瘤 10%**}}
- Cushing's disease：{{o|**microadenoma 90%**}}

### 篩檢
- {{o|24 小時尿 free cortisol > 100 μg/day}}
- {{b|**1 mg overnight dexamethasone**}}：{{o|晚上 11 點吃、隔天早上 8 點 cortisol 無法抑制到 **< 1.8 μg/dL**（50 nmol/L）}}
- Late night salivary cortisol
- {{g|**Pseudo-Cushing（偽陽性）：肥胖、酒精、憂鬱或壓力、腎衰竭**}}

### 病因鑑別
- {{o|**ACTH < 10 pg/mL → ACTH 非依賴 → 腎上腺 CT/MRI**}}；{{o|> 10 → 依賴 → 腦下垂體 MRI、HDDST、CRH test}}
- {{p|**BIPSS**：確定是否為 Cushing's disease 的診斷力高，但**左右定位（lateralization）有限**}}

![Cushing 症候群確診後的病因鑑別流程](img/1pfSVCzT4-1v8J_jJkJwDRjkQcdulKlRk/p117.webp)

### 表現與治療
- 近端肌無力、中心性肥胖、水牛肩、紫紋、瘀青；{{p|**白血球增加、淋巴球減少**}}；{{p|**深部靜脈栓塞與肺栓塞風險都增加**}}
- 治療首選**手術**：Cushing's disease → {{b|transsphenoidal surgery}}；腎上腺腫瘤 → {{b|adrenalectomy}}；異位 ACTH → 切除腫瘤
- 藥物：{{b|steroidogenesis 抑制劑：ketoconazole、metyrapone、mitotane、osilodrostat}}；腫瘤導向：{{b|pasireotide、cabergoline}}
- {{p|**Metyrapone 抑制 11β-hydroxylase（合成）**，不是阻斷受體}}

### 考題重點
- {{r|Cushing **錯誤**：**遠端肌肉無力**}}（考古，年份未標；應為近端）
- {{r|正確：**IPSS 可幫助分辨是否為 Cushing's disease，但定位不一定可靠**}}（考108，答 D）
- {{r|最正確：**LDDST 0.5 mg q6h 兩天後 cortisol < 50 nmol/L 可先排除**}}（考111，答 B）
- {{r|ACTH 依賴型鑑別正確：(2) 異位病程快、肌病變重 (4) ACTH 重疊高無法區分 (5) IPSS 基礎比值 > 2、CRH 後 > 3，敏感度 > 95%}}（考112，答 C）；{{p|(1) 腦下垂體瘤**女多於男**、異位**男多於女**；(3) 低血鉀比例約 10% vs 57～100%}}
- {{r|左腎上腺 3.3 cm、ACTH < 5、cortisol 無晝夜變化 → **Cushing 可能增加 DVT 或肺栓塞風險**}}（考111，答 B）；{{p|術後仍要補 hydrocortisone}}
- {{r|吃不明藥（含 dexamethasone）後體重增加、圓臉、ACTH 與 cortisol 都低 → **慢慢 taper 糖皮質素並做復健**}}（考104，答 E）

- {{r|休克、低血壓低血鈉低血糖 → **乳暈顏色淡、無腋毛 → ACTH 低、cortisol 低**}}（考107，答 E）；{{p|不要等報告，先給 hydrocortisone}}

## 嗜鉻細胞瘤與副神經節瘤（PPGL）

### 表現
- 腎上腺素過多發作（{{g|**5H**}}）：**Hypertension（50%）、Headache（40%）、Hyperhidrosis（60%）、Hypermetabolism、Hyperglycemia**；{{g|頭痛 + 冒汗 + 心悸 = triad}}
- 也可能姿勢性低血壓（epinephrine 作用於 β2）、多尿、高血鈣（PTHrP）
- {{p|**有些病人可多年無症狀**}}；未診斷可能出現高血壓危象、肺水腫、心肌梗塞、中風

### 診斷
- {{b|**血漿游離 metanephrines**：敏感度最高}}；偽陽性多與抽血姿勢與壓力有關
- 造成偽陽性的藥物：{{b|**三環抗憂鬱劑**、α/β blocker、利尿劑、MAOI、levodopa}}；TCA、opiates、metoclopramide 也可能**誘發發作**
- {{p|**CT/MRI 可以打顯影劑**}}；unenhanced CT {{o|通常 **> 10 HU**}}
- {{p|**所有人都要做基因檢測**}}：{{o|**30～35% 生殖細胞突變**、35～40% 體細胞突變}} → {{g|推翻 rule of ten}}
- 遺傳性病人發病年齡較早
- 病理：**zellballen**（chief cells 被 sustentacular cells 包圍）；{{p|chromogranin A、**synaptophysin**、CD56 陽性}}
- {{g|**SDHB 染色消失 → 查 SDHx 生殖細胞突變**；SDHx 相關：惡性潛能高、多在腎上腺外、多發、家族性}}
- {{p|**現行 WHO 視所有 PPGL 為具轉移潛能的惡性腫瘤**}}

### 術前準備
- {{b|**α-blocker 至少 2 週**}}、補充水分
- {{b|CCB 為第二線}}；{{b|β-blocker 只用於心搏過速或心律不整}}
- {{p|**絕不能在 α-blockade 之前用 β-blocker**}}（阻斷血管擴張 → 血壓暴衝）
- 術後低血壓以輸液處理，不建議升壓劑

### 考題重點
- {{r|**錯誤**：**rule of ten 包括 10% 單側**}}（考古，年份未標；應為雙側）
- {{r|敏感度最高、特異性佳的：**血漿游離 metanephrines**}}（考古，年份未標）
- {{r|正確：**常以心悸、頭痛、冒汗表現，但也有病人多年無症狀**}}（考107，答 A）
- {{r|最正確：**症狀通常明顯，但某些病人可無症狀數年**}}（考111，答 A）
- {{r|**不正確**：**5～10% 為惡性，只有淋巴或遠處轉移才算惡性**}}（考112，答 E）；{{p|依 2017 年後 WHO，所有 PPGL 都視為具轉移潛能，已不用「良性/惡性」區分，改稱 metastatic；此題其他選項都符合教科書，這個判斷較有爭議}}
- {{r|正確：**可有多尿、多渴、姿勢性低血壓、高血糖、高血鈣**}}（考113，答 A）；α/β blocker 造成**偽陽性**；synaptophysin **陽性**；遺傳約 **35～40%**；unenhanced CT > 10 HU
- {{r|最正確：**偉大的偽裝者，可頭痛、冒汗、心悸、焦慮、低血壓，也可數年無症狀**}}（考114，答 B）；rule of tens 是 10% **惡性**；可以打顯影劑；CCB 可作為第二線；MEN2B **包括** MTC

## 腎上腺偶發瘤

### 兩個問題
- {{p|**有沒有功能？**}}：cortisol（{{b|1 mg DST}}）、醛固酮（高血壓或低血鉀時查 ARR）、{{b|血漿 metanephrine}}
- {{p|**是不是惡性？**}}：大小、{{o|unenhanced CT **< 10 HU** 屬良性 lipid-rich adenoma}}；{{o|≥ 4 cm}} 要警覺
- {{p|**不要對腎上腺腫瘤做細針穿刺**}}（嗜鉻細胞瘤可能引發危象）
- {{o|約 5% 偶發瘤是嗜鉻細胞瘤}}；{{o|腎上腺皮質癌約 60～70% 有類固醇過量表現}}

### 考題重點
- {{r|60 歲難控制高血壓、右腎上腺 3 cm 腫瘤 → 最有幫助：**aldosterone/PRA + 1 mg DST + plasma metanephrine**}}（考104，答 D）
- {{r|最正確：**約 60～70% 腎上腺皮質癌有類固醇過量表現**}}（考114，答 E）；ACTH 與 cortisol 都高**不是**醫源性；乳暈淡、毛少是 ACTH **低**；HDDST 無法抑制應找**異位**來源；< 20 HU 較可能良性

# 腦下垂體

## 概論

### 荷爾蒙
- 前葉 6 種：**PRL、GH、ACTH、LH、FSH、TSH**
- 後葉：**AVP（ADH）、oxytocin**
- 大腫瘤局部壓迫：{{p|**視野缺損（bitemporal hemianopia）**}}、頭痛、腦神經麻痺、腦下垂體功能低下
- 分泌 PRL 的腫瘤可同時分泌其他荷爾蒙（GH + PRL、ACTH + PRL、TSH + PRL）

## 泌乳激素瘤

### 高泌乳激素血症
- 表現：月經異常、泌乳、不孕、陽痿
- 次發原因：{{b|**metoclopramide（Primperan）、H2 blocker**}}（dopamine 抑制 PRL）、{{p|**原發性甲狀腺低下**（TRH 刺激 PRL）}}、{{o|**CKD 約 30%**}}
- {{p|泌乳激素瘤是**最常見**的功能性腦下垂體腫瘤}}

### 治療
| | Microprolactinoma | Macroprolactinoma | Giant |
|---|---|---|---|
| 大小 | {{o|< 1 cm}} | {{o|> 1 cm}} | {{o|> 4 cm}} |
| PRL（ng/mL） | {{o|100～250}} | {{o|> 250}} | {{o|數千以上}} |

- {{p|**女性無症狀 microprolactinoma → 不需治療，追蹤**}}；無月經 → dopamine agonist 或口服避孕藥
- {{b|**Cabergoline 0.5 mg 每週 1～2 次**：副作用較輕}}；{{b|Bromocriptine 1 顆每天 2～3 次：噁心嘔吐較多}}
- {{p|**懷孕後停藥**}}；手術只用於無法耐受或巨大腫瘤合併腦脊髓液滲漏

### 考題重點
- {{r|正確：**女性無症狀 microadenoma 不須治療，追蹤即可**}}（考108，答 B）
- {{r|最正確：(1) 占功能性腦下垂體瘤 70% 以上 (2) 可同時分泌兩種以上荷爾蒙 (4) PRL 與腫瘤大小正相關，> 250 通常 > 1 cm}}（考110，答 A）；macroadenoma 男女約相當；考慮懷孕用 **bromocriptine**
- {{r|**不正確**：**PRL > 150 腫瘤都大於 1 公分**}}（考111，答 B）

## 肢端肥大症

### 診斷與治療
- {{p|**IGF-1 上升**（依年齡）}}；{{p|**隨機 GH 沒有價值**}}（脈衝式分泌）
- {{o|**75 g OGTT 2 小時 GH 無法抑制到 < 1 ng/mL**}}
- 治療：{{b|**手術（TSA，快）**}}、{{b|somatostatin analogue（快）}}、{{b|GH receptor antagonist（快）}}、{{b|dopamine agonist（數週）}}、{{b|γ-knife（慢，數年）}}；{{p|macroadenoma 通常三種都要用到}}
- {{o|約 25% 同時 PRL 上升}}

### 考題重點
- {{r|正確：**青春期 IGF-1 參考值較高**}}（考108，答 A）；術前可以給 somatostatin analogue；放療要好幾年才有效
- {{r|正確：**約 25% 肢端肥大症同時 PRL 增高**}}（考105，答 D）

## 尿崩症（DI）

### 診斷
- 定義：{{o|**24 小時尿量 > 50 mL/kg、尿滲透壓 < 300 mOsm/L**}}；{{o|尿比重 < 1.005}}
- {{b|**限水試驗**}} → 給 DDAVP 後{{o|尿滲透壓上升 **> 50%** → central DI}}；沒反應 → nephrogenic DI
- MRI：{{p|**後葉亮點消失**、垂體柄 > 2～3 mm → central DI}}；{{p|亮點存在較能排除 central DI，**primary polydipsia 亮點仍在**}}
- Nephrogenic DI 原因：{{b|**lithium、amphotericin B、aminoglycosides、cisplatin**}}、{{p|**高血鈣、低血鉀**}}、sarcoidosis（central 與 nephrogenic 都可能）
- 懷孕 DI：{{o|第二、三孕期}}（胎盤 vasopressinase）
- 治療：central → {{b|DDAVP}}；nephrogenic → {{b|thiazide、amiloride、indomethacin}}；{{p|**primary polydipsia 不可用 DDAVP**（低血鈉）}}

### 考題重點
- {{r|年輕男性一天喝 5 L 冷飲 → 必要檢查：**限水試驗、dDAVP test、plasma Osm**}}（考101，答 A）
- {{r|正確：(1) 尿量 < 40 mL/kg 且尿滲透壓 > 300 → 先查泌尿系統 (2) 尿量 > 40、滲透壓 < 300、AVP < 1 → central DI 或 primary polydipsia (5) 限水後給 DDAVP 尿滲透壓仍 250 → nephrogenic DI}}（考109，答 C）
- {{r|最正確：**lithium、amphotericin B、aminoglycosides 可能導致 nephrogenic DI**}}（考111，答 C）
- {{r|**不正確**：**高血鉀造成 nephrogenic DI**}}（考113，答 E；應為**低**血鉀）

## 腦下垂體功能低下

### 重點
- {{p|**處置順序：先補 hydrocortisone，再補甲狀腺素**}}（反過來會誘發腎上腺危象）
- 詢問**月經與生產史**（Sheehan syndrome）
- **Pituitary apoplexy**：原有腺瘤內出血 → {{p|**急性劇烈頭痛、視力模糊**、意識改變}}；{{b|**立即高劑量類固醇**}}、需要時手術減壓；日後可能 **empty sella**
- 停經後 LH、FSH 應該很高；{{p|**偏低表示腦下垂體功能低下**}}

![Hypophysitis 分類：lymphocytic、granulomatous、xanthomatous](img/1pfSVCzT4-1v8J_jJkJwDRjkQcdulKlRk/p158.webp)

- {{g|**Lymphocytic hypophysitis**：常見於**懷孕後期或產後女性**，MRI 見**腦下垂體均勻增大、垂體柄增厚**（不是 empty sella）}}；治療觀察或糖皮質素

### 考題重點
- {{r|意識不清、皮膚粗乾、乳頭顏色淡、低血鈉低血糖 → **立即抽 ACTH、cortisol、fT4、TSH + 優先補 hydrocortisone + 詢問月經生產史**}}（考105，答 D）
- {{r|肢端肥大病人突發劇烈頭痛、視野模糊、意識不清 → **(1) 腦下垂體瘤內出血 (3) 立即高劑量類固醇 (4) 儘速手術減壓 (5) 未來可能 empty sella**}}（考108，答 D）
- {{r|最支持 hypopituitarism：**insulin 低血糖試驗 cortisol 只到 9、TRH 刺激後 TSH 只到 4.25**}}（考109，答 B）
- {{r|81 歲女性腦下垂體腫瘤、停經後 LH/FSH 偏低 → **(3) 應考慮 hypopituitarism (4) 先給類固醇**}}（考111，答 D）
- {{r|Lymphocytic hypophysitis **錯誤**：**MRI 會發現 empty sella**}}（考古，年份未標）

# 自體免疫多腺體症候群（APS）

### APS-1 與 APS-2
- 免疫耐受喪失，至少兩個內分泌腺功能**低下**

| | APS-1 | APS-2 |
|---|---|---|
| 三大表現 | {{g|**皮膚黏膜念珠菌病 + 副甲狀腺低下 + Addison**}} | {{g|**T1DM + 自體免疫甲狀腺病 + Addison**}} |
| 發病 | {{p|**兒童期**}}，念珠菌通常最早 | 成人，女 > 男 |
| 其他 | 抗 interferon（細胞激素）抗體 | 性腺低下、重症肌無力、**乳糜瀉**、惡性貧血 |

- 診斷：三項中符合兩項
- 抗體：TPO Ab（甲狀腺）、GAD Ab（T1DM）、{{p|**21-hydroxylase Ab（Addison）**}}
- {{p|兩型都可能出現 Graves' disease}}

### 考題重點
- {{r|APS-2 **不常見**的：**慢性皮膚黏膜念珠菌病**}}（考112，答 E；那是 APS-1）
- {{r|**不正確**：**APS-1 發病年齡通常 30～40 歲**}}（考113，答 C；應為兒童期）；{{p|用 ketoconazole 治療念珠菌要小心誘發腎上腺危象}}
