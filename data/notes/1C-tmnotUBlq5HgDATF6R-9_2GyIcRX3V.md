# 糖尿病診斷與分型

## 診斷標準

### 糖尿病與前期
| 檢查 | 糖尿病前期 | 糖尿病 |
|---|---|---|
| 空腹血糖（FPG，{{o|至少 8 小時未進食}}） | {{o|100～125}} | {{o|**≥ 126 mg/dL**}} |
| OGTT 75 g 2 小時 | {{o|140～199}} | {{o|**≥ 200 mg/dL**}} |
| 隨機血糖 | 不適用 | {{o|**≥ 200 mg/dL** + 典型症狀}}（多尿、多喝、體重減輕） |
| HbA1c | {{o|5.7～6.4%}} | {{o|**≥ 6.5%**}} |

- {{p|沒有明確高血糖時，需**重複檢驗**確認}}

### HbA1c 不可靠的情況
- HbA1c 反映紅血球壽命（{{o|約 120 天}}）內的加權平均
- {{p|**紅血球更新加快 → HbA1c 假性偏低**}}：鐮刀型貧血、**懷孕第二三期**、G6PD 缺乏、**血液透析**、最近失血或輸血、EPO 治療
- {{p|**紅血球更新變慢 → 偏高**：缺鐵性貧血}}
- 血紅素變異、HIV 使用某些藥物

### 考題重點
- {{r|糖尿病診斷標準**錯誤**的：**隨機血糖 ≥ 140 mg/dL 合併典型症狀**}}（考108；應為 ≥ 200）
- {{r|CLL 化療中發現高血糖 230～280、Hb 8、HbA1c 6.3% → **HbA1c 因貧血而不準確**}}（考104）

## T1DM vs T2DM

### 比較
| | T1DM | T2DM |
|---|---|---|
| 發病 | 急性、有症狀 | 緩慢、無症狀 |
| 臨床 | 體重減輕、多尿、多喝 | 肥胖、強烈家族史、acanthosis nigricans、PCOS |
| 酮症 | 通常有 | 通常沒有 |
| 空腹 C-peptide | {{o|**< 0.5 ng/mL**}} | {{o|> 0.5}} |
| 升糖素刺激後 6 分鐘 C-peptide | {{o|**< 1.8 ng/mL**（上升 < 0.7）}} | {{o|> 1.8（上升 > 0.7）}} |
| 自體抗體（anti-GAD、IA2、ZnT8） | 陽性 | 陰性 |
| 治療 | 胰島素 | 生活型態 → 口服藥 → 胰島素 |

- 自體抗體敏感度：{{o|**GAD65 70～90%**}}、IAA 40～70%、IA2 50～70%、ZnT8 50～70%；{{o|特異度都約 99%}}
- T1DM 自然史：Stage 1（自體免疫、血糖正常、無症狀）→ Stage 2（自體免疫、血糖異常、無症狀）→ Stage 3（有症狀）
- {{p|T2DM 的病理：程度不一的**胰島素阻抗**、**胰島素分泌減少**、**肝臟糖質新生增加**}}；β 細胞功能隨時間逐漸下降

### 考題重點
- {{r|T2DM **錯誤**的敘述：**一旦須注射胰島素就轉變成第一型**}}（考古，年份未標）
- {{r|**不是**診斷 T1DM 必要條件的：**糖尿病酮酸中毒**}}（考109）

## LADA 與其他分型

### LADA（latent autoimmune diabetes of adults）
- 緩慢進展的免疫相關糖尿病，兼具 T1DM 與 T2DM 遺傳特徵（type 1.5）；{{p|常被誤診為 T2DM}}
- 定義：{{o|**年齡 > 30 歲**}}、{{p|**β 細胞自體抗體陽性（GAD65 最常見）**}}、{{o|**診斷後至少前 6 個月不需胰島素**}}
- {{r|LADA **錯誤**敘述：**β 細胞功能喪失速度比 T1DM 快**}}（考古，年份未標；應為較慢）

### WHO 2019 分類
- T1DM、T2DM
- **Hybrid forms**：slowly evolving immune-mediated diabetes of adults（LADA）、**ketosis-prone T2DM**
- 其他特定類型：單基因、外分泌胰臟疾病、內分泌疾病、藥物、感染等
- 懷孕首次發現的高血糖：**懷孕中的糖尿病（overt）**、**妊娠糖尿病（GDM）**

## 妊娠糖尿病（GDM）

### 重點
- 懷孕期間**首次發現**的葡萄糖耐受不良
- {{p|**第一次產檢**就要用標準診斷條件篩檢是否原本就有糖尿病或前期}}；{{p|懷孕中符合糖尿病診斷者屬於 **overt diabetes**，不是 GDM}}
- 機轉：{{p|**胎盤分泌 human placental lactogen（HPL）造成胰島素阻抗** + 母體肥胖}}
- 一步法：{{o|懷孕 **24～28 週** 75 g OGTT}}，符合任一即診斷：{{o|**空腹 ≥ 92、1 小時 ≥ 180、2 小時 ≥ 153 mg/dL**}}
- {{o|35～60% 在 10～20 年內會進展為糖尿病}}；{{p|GDM 病史者**至少每 1～3 年**篩檢}}；其子女未來糖尿病風險也較高

### 考題重點
- {{r|GDM **最不適當**的：**將來發生 T2DM 的風險跟一般人接近**}}（考古，年份未標）
- {{r|**錯誤**的（答 E）：(1) 主要與胰島素分泌不足相關、(3) 懷孕後期胰島素阻抗明顯降低}}（考109）
- {{r|**錯誤**的：**主要與懷孕時胰島素分泌不足相關**}}（考110；應為胰島素阻抗）

## 篩檢對象

### 無症狀成人篩檢
- {{o|BMI **≥ 25**（亞洲人 **≥ 23**）}}合併任一危險因子：一等親糖尿病、高風險族群、**心血管疾病史**、{{o|**高血壓（≥ 130/80 或服藥）**}}、{{o|HDL < 35 或 TG > 250}}、PCOS、缺乏運動、胰島素阻抗相關狀況
- 糖尿病前期：每年檢查
- {{p|有 GDM 病史：**至少每 1～3 年**}}
- {{o|其他人：**35 歲**開始篩檢}}；正常則至少每 3 年重複

# 血糖控制目標

## 個人化目標

### 一般成人
- {{o|HbA1c **< 7.0%**}}、{{o|餐前 **80～130 mg/dL**}}、{{o|餐後尖峰 **< 180 mg/dL**}}
- 較嚴格：病程短、低血糖風險低、藥物有心腎體重好處、無心血管併發症
- 較寬鬆：病程長、低血糖風險高、已有心血管併發症、嚴重共病

![依健康狀態的 HbA1c 與 CGM 目標](img/1C-tmnotUBlq5HgDATF6R-9_2GyIcRX3V/p020.webp)

- {{o|健康狀況好、治療負擔低：< 6.5%；多數成人：< 7.0%；健康老人：< 7.5%；複雜或中度健康老人：< 8.0%；非常複雜或預期壽命有限：不設 HbA1c 目標（避免症狀性高血糖）}}

### 懷孕
- {{o|HbA1c **< 6%**（若無低血糖）}}；可用 glycated albumin 輔助
- {{p|紅血球更新加快 → HbA1c 偏低}}；HbA1c 無法反映造成巨嬰的**飯後高血糖** → 更頻繁監測（例如每月）

## 連續血糖監測（CGM）

### 重點
- 測**組織間液**血糖，與血糖差約 5 分鐘；藍牙傳輸
- 指標：TIR、高血糖、低血糖、血糖波動；以 AGP 呈現
| 族群 | 目標範圍 | TIR 目標 |
|---|---|---|
| T1D 與 T2D | {{o|70～180 mg/dL}} | {{o|**> 70%**（> 16 小時 48 分）}} |
| 老人或高風險 | {{o|70～180 mg/dL}} | {{o|**> 50%**（> 12 小時）}} |
| 懷孕 T1D | {{o|63～140 mg/dL}} | {{o|> 70%}} |
| 懷孕 GDM 與 T2D | {{o|63～140 mg/dL}} | 無 |

- {{o|TBR < 70：< 4%；TBR < 54：< 1%；TAR > 180：< 25%；TAR > 250：< 5%}}（一般成人）
- {{p|TIR 每增加 5% 都有臨床上顯著的好處}}

## ABC 控制

### 目標
- {{o|**A**：HbA1c < 7%}}
- {{o|**B**：血壓 < 140/90 mmHg}}（講義）；{{b|首選 **ACEI 或 ARB**}}
- {{o|**C**：LDL < 100 mg/dL；有明顯 CVD < 70 mg/dL}}

### 考題重點
- {{r|老年糖尿病腎病變**錯誤**的：**年紀愈長應把 HbA1c 控制在 < 6.5%**}}（考109）
- {{r|78 歲、反覆感染住院的奶奶，**錯誤**的：**未來 HbA1c 目標 < 6.5%**}}（考109）
- {{r|**錯誤**的（答 E）：(3) LDL 目標 < 130、(4) 血壓目標 < 120/80（蛋白尿 < 110/70）、(5) 達標後戒菸無助於降低併發症}}（考113）

# 糖尿病血脂異常

## 脂蛋白與機轉

### 重點
- VLDL：攜帶肝臟釋出的 **TG**；乳糜微粒：攜帶飲食 **TG**；LDL：攜帶**膽固醇**；HDL：從血管壁帶走膽固醇
- {{p|糖尿病血脂異常：胰島素作用不足 → FFA 增加 → VLDL 與乳糜微粒過度生成 → **TG 高、HDL 低、small dense LDL 增加**}}

## 降血脂藥

### 比較
| 藥物 | 機轉 | 效果 | 副作用 |
|---|---|---|---|
| {{b|Statin}} | HMG-CoA reductase inhibitor | 減少膽固醇合成 | 肝毒性、肌肉病變 |
| {{b|Bempedoic acid}} | ATP citrate lyase（ACLY）inhibitor | 減少膽固醇合成 | {{p|痛風}} |
| {{b|Ezetimibe}} | 抑制腸道膽固醇吸收（NPC1L1） | 減少腸道吸收 | 併用 statin 時 ALT 上升 |
| {{b|PCSK9 inhibitor}} | 結合循環中的 PCSK9 | 減少 LDL receptor 分解 | 肌肉痛、背痛 |

## 台灣血脂指引

### 初級預防（2022）
- {{p|**糖尿病、CKD 或 LDL ≥ 190 → 高風險，開始藥物，LDL 目標 < 100**}}
- 其他依危險因子數（高血壓、男 ≥ 45 或女 ≥ 55、早發 CAD 家族史、HDL 低、吸菸、代謝症候群）：{{o|≥ 2 個 → < 115；1 個 → < 130；0 個 → < 160}}；先非藥物 3 個月，再中強度 statin

### 次級預防（2017）
- {{p|ACS → statin 或 statin + ezetimibe，LDL 目標 **< 70**}}；{{p|**ACS 合併糖尿病 → 可考慮 < 55**}}
- 未達標 → 加 PCSK9 inhibitor

### 考題重點
- {{r|糖尿病、冠心病放支架、LDL 已達標（52），但 **TG 828** → 加 **fenofibrate**}}（考112）
- {{r|72 歲同樣情境、LDL 46、**TG 625**、背景型視網膜病變 → **fenofibrate**}}（考114）
  - {{g|LDL 已低於極高風險目標（< 55），首要是降 TG；fenofibrate 對糖尿病視網膜病變也有保護效果}}
- {{r|2017 台灣指引**錯誤**的：**40 歲以下糖尿病患無論有無心血管病史都不宜使用 statin**}}（考109）
  - 正確：ACS 合併糖尿病 LDL < 55；首選 statin；合併心血管風險 < 70；40 歲以上無心血管病史 < 100

# 降血糖藥物

## 分類

### 依是否依賴血糖
- {{g|**葡萄糖依賴（不易低血糖）**：GLP-1 RA、DPP-4 inhibitor、α-glucosidase inhibitor}}
- {{g|**不依賴葡萄糖（易低血糖）**：外源性胰島素、**sulfonylurea、glinide**}}
- 依機轉：
  - 促進胰島素分泌：SU、glinide、incretin 類
  - 改善胰島素阻抗：metformin、pioglitazone
  - {{p|**抑制腎臟葡萄糖再吸收：SGLT2 inhibitor（與胰島素無關）**}}
- 胰島素分泌機轉：葡萄糖經 **GLUT2** 進入 β 細胞 → ATP 增加 → 關閉 K 通道 → 去極化 → 鈣離子流入 → 釋放胰島素

### 各類比較
| 類別 | 機轉 | HbA1c | 體重 | CV 好處 | CKD 保護 |
|---|---|---|---|---|---|
| {{b|Biguanide}} | 減少肝臟葡萄糖產生 | +++ | ↓ | + | ↔ |
| {{b|Sulfonylurea}} | 增加胰島素分泌 | +++ | ↑ | ↔ | ↔ |
| {{b|TZD}} | 減少胰島素阻抗 | +++ | ↑ | ± | ↔ |
| {{b|DPP-4i}} | 增加胰島素、減少升糖素 | ++ | ↔ | ↔ | ↔ |
| {{b|α-glucosidase i}} | 延緩碳水化合物吸收 | + | ↓ | + | ↔ |
| {{b|SGLT2i}} | 增加腎臟排糖與排鈉 | ++ | {{g|↓↓}} | {{g|+++}} | {{g|+++}} |
| {{b|GLP-1 RA}} | 增胰島素、減升糖素、延緩胃排空 | +++ | {{g|↓↓↓}} | {{g|++}} | {{g|++}} |
| {{b|GLP-1／GIP dual}} | 同上 + 增胰島素敏感度 | +++ | {{g|↓↓↓↓}} | ? | ? |

## 胰島素促泌劑

### Sulfonylurea 與 glinide
| 藥物 | 每日劑量 | 作用時間 | 排除 |
|---|---|---|---|
| {{b|Gliclazide（Diamicron）}} | 30～120 mg | 24 小時 | 肝 |
| {{b|Glimepiride（Amaryl）}} | 1～8 mg | 24 小時 | 肝 + 腎 |
| {{b|Mitiglinide（Glufast）}} | 10 mg tid | 2～4 小時 | 腎 |

- {{g|SU 控制**空腹**血糖；glinide 控制**飯後**血糖}}
- {{p|關閉 K 通道、**不依賴葡萄糖** → 低血糖}}；{{p|老人腎功能差時 SU 是低血糖的重要原因}}

## Incretin 類

### 機轉
- {{p|**GLP-1 由腸道 L cell 分泌**}}；GIP 由 K cell 分泌
- {{o|GIP 半衰期 4～5 分鐘、GLP-1 2～3 分鐘}}，被 **DPP-4** 分解
- T2DM 病人的 incretin effect 減弱
- GLP-1 作用：{{p|增加胰島素分泌、**減少升糖素**}}、延緩胃排空、減少食慾、心臟與神經保護、增加周邊葡萄糖利用、減少肝臟葡萄糖產生

### GLP-1 RA 與 tirzepatide
- {{b|Liraglutide：糖尿病 0.6 → 1.2 → 1.8 mg；肥胖 3.0 mg}}
- {{b|Semaglutide：糖尿病 0.25 → 0.5 → 1.0 mg；肥胖 1.7 → 2.4 mg；口服 3 → 7 → 14 mg}}
- {{b|**Tirzepatide（猛健樂）**：**GIP／GLP-1 雙重受體促效劑**，2.5 → 5 → … → 15 mg}}
- 減重 5～10% 以上可改善血糖、TG、血壓、PCOS、OSA、脂肪肝、膝關節炎、HFpEF；{{o|> 15% 可讓 T2DM 緩解、降低全死因與 CV 死亡}}

### 考題重點
- {{r|Incretin 正確的：**GLP-1 由 L cell 分泌、GLP-1 RA 可減輕體重、可降低食慾並延緩胃排空**（答 B：1+3+5）}}（考105）
  - {{g|錯誤：GLP-1 也刺激升糖素分泌（是抑制）；T1DM 也適用 GLP-1 RA}}

## Metformin 與 TZD

### Metformin（biguanide）
- {{p|減少**肝臟葡萄糖產生**、增加葡萄糖利用}}；體重下降、**不會低血糖**
- 副作用：腹瀉、{{p|**維生素 B12 缺乏**}}、{{p|**乳酸中毒**（罕見，但死亡率可達 **50%**）}}
- {{p|**eGFR < 30 禁用**}}
- {{o|500～2500 mg/天（最大 850 mg tid = 2550 mg）}}；可延緩糖尿病前期進展；懷孕可考慮

### TZD（pioglitazone）
- **PPARγ agonist**（肌肉、脂肪組織）：減少胰島素阻抗、增加葡萄糖利用
- {{p|副作用：**水腫、心衰竭、骨質疏鬆**、體重與脂肪增加}}；{{p|**不會低血糖**}}
- {{p|HFrEF 或水腫時**不應使用**}}

### 考題重點
- {{r|Metformin **不正確**的：**eGFR < 30 使用是安全的**}}（考114）
- {{r|Metformin **錯誤**的：**每日最高劑量為 2000 mg**}}（考113；最高約 2550 mg）
- {{r|TZD 副作用：**骨質疏鬆、體重增加、脂肪組織增加**（答 A：1+3+5）}}（考112）
- {{r|會增加**骨質疏鬆**風險的糖尿病藥：**TZD**}}（考114；停經婦女骨折風險增加）

## SGLT2 inhibitor

### 機轉
- 正常腎糖閾值：{{o|血糖 > 180 mg/dL}} 才出現尿糖；糖尿病時近端腎小管肥厚、SGLT2 表現增加 → 再吸收更多
- {{p|抑制 SGLT2 → **尿糖（約 80 g/天 ≈ 240 kcal）**、滲透性利尿、**排鈉**}}
- {{p|**不需依賴胰島素**；低血糖風險低}}（後段 SGLT1 代償）
- {{p|器官保護：**HFrEF、HFpEF、CKD**（eGFR、白蛋白尿）}}

### 副作用
- {{p|**生殖器黴菌感染**（女性外陰陰道念珠菌、**男性龜頭炎**）、泌尿道感染}}
- 滲透性利尿：多尿、脫水、頭暈、低血壓
- {{p|**Euglycemic DKA**}}、急性腎損傷（尤其脫水時）
- {{p|**Sick day rule：嚴重疾病時暫停**}}

### 考題重點
- {{r|SGLT2i **錯誤**的：**女性容易泌尿道感染，但男性則無此困擾**}}（考106）
- {{r|SGLT2i **錯誤**的：**同時降低酮酸中毒的機率**}}（考113；實際上會增加 euglycemic DKA）
- {{r|**非胰島素相關**機轉的降血糖藥：**SGLT2 inhibitor**}}（考113）
- {{r|具有**增加排除尿鈉**藥理機轉：**SGLT2 inhibitor**}}（考112）

## 治療策略與實證

### ADA 與 DAROC 指引
- {{p|先評估共病：**ASCVD、心衰竭、CKD** → 優先選有器官保護實證的藥物（**SGLT2i、GLP-1 RA**）}}
- 目標為體重與血糖 → 選減重效果好的藥（GLP-1 RA、tirzepatide）
- DAROC 2022：{{p|**Metformin + 生活型態**為基礎}}；{{o|HbA1c 高於目標 **1.5%** 以上 → 建議兩種藥}}；合併高血糖症狀 → 先用胰島素
- {{p|**SU 與 glinide 不建議合併；DPP-4i 與 GLP-1 RA 不建議合併**}}
- {{p|**Saxagliptin 可能增加心衰竭住院**}}（SAVOR-TIMI 53）

### 考題重點
- {{r|實證可降低 MACE 的：**GLP-1 RA、SGLT2i**（答 E：2+5）}}（考111）
- {{r|**錯誤**的（答 E）：(1) eGFR < 45 就不應用 metformin（應為 < 30）、(4) TZD 常見低血糖、(5) DPP-4i 有心血管保護}}（考110）
- {{r|68 歲、eGFR 40、UACR 210、NPDR，用 metformin + sitagliptin，**錯誤**的：**DPP-4i 與 GLP-1 RA 合併使用可加強血糖控制**}}（考114）
  - {{g|正確：加 SGLT2i 可延緩腎功能惡化；metformin 可繼續（eGFR < 30 才禁用）；GLP-1 RA 可合併；UACR > 200 即使血壓未超過 140/90 仍應用 ACEi／ARB}}
- {{r|75 歲 HFrEF 合併糖尿病，**最不適合**：**加上 saxagliptin**}}（考114）
  - {{g|正確：SGLT2i 改善心衰；metformin 可繼續；不應用 pioglitazone；胰島素可後線}}
- {{r|83 歲、eGFR 28、下肢水腫、HbA1c 8.6 → **linagliptin**}}（考114，講義未收錄）
  - {{g|Linagliptin 是唯一主要經膽汁與腸道排除的 DPP-4i，**腎功能差不需調劑量**、單用極少低血糖；metformin、SGLT2i 在 eGFR < 30 不適合；SU 易低血糖；TZD 會加重水腫}}

## 胰島素治療

### 種類與原則
- 超短效、短效、中效、長效
- {{b|**Basal insulin**（長效，Toujeo、Tresiba）：抑制肝臟葡萄糖輸出（兩餐間與夜間）}}
- {{b|**Prandial insulin**（速效，Apidra、NovoRapid、RI）：促進葡萄糖攝取、限制飯後高血糖}}
- {{o|**MDII 起始總劑量 0.5 U/kg**：basal 50～60%、bolus 40～50%}}
- {{o|**Basal insulin 起始劑量 0.2 U/kg/day**}}
- {{p|**先調空腹（先調 basal），再處理餐後**}}（fix fasting first）
- 共配方：**Ryzodeg**（70% 超長效 + 30% 速效），QD 或 BID
- 固定比例合併：basal insulin + GLP-1 RA（例如 insulin glargine 10～40 U）
- 生理：{{p|內源性胰島素直接進入**門靜脈**；皮下注射則進入全身循環，到肝臟濃度較低（subphysiologic）}}
- β 細胞功能隨病程下降：胰島素用途從 augmentation → rescue → replacement

### 考題重點
- {{r|**錯誤**的：**最符合生理需求的方式是一天一次長效基礎胰島素**}}（考110；應為 basal-bolus）
- {{r|**錯誤**的：**GLP-1 RA 可以合併胰島素治療第一型糖尿病**}}（考112、114）
  - {{g|T1DM 使用 GLP-1 RA 因 DKA 與腸胃副作用較高，**尚未被 FDA 核准**}}
  - 正確：basal insulin 可合併 GLP-1 RA；GLP-1 RA 常見腹脹噁心、胰島素常見低血糖；GLP-1 RA 可減重；basal 起始 0.2 U/kg/day

# 高血糖危象（DKA 與 HHS）

## 病理與比較

### 誘發因子
- {{p|**感染**、漏打胰島素、急性疾病、心肌梗塞或中風}}
- DKA：**絕對**胰島素缺乏 → 脂肪分解、FFA → **酮體**生成 → 酮酸中毒
- HHS：**相對**胰島素缺乏 → 高血糖、滲透性利尿、脫水 → 高滲透壓

### 臨床比較
| DKA | HHS |
|---|---|
| {{o|數小時到數天}}發展 | {{o|數天到一週}} |
| 通常清醒 | {{p|常有意識改變}} |
| 噁心、嘔吐、腹痛 | 常合併其他急性疾病 |
| {{p|Kussmaul 呼吸}} | |

- 兩者都有多尿、多喝、體重減輕、脫水
- {{p|**約 1/3 為 DKA／HHS 混合型**}}

![DKA 與 HHS 診斷標準、DKA 嚴重度分級](img/1C-tmnotUBlq5HgDATF6R-9_2GyIcRX3V/p085.webp)

### 診斷標準（ADA 2024）
- {{o|**DKA**：血糖 **≥ 200** 或已知糖尿病；**β-hydroxybutyrate ≥ 3.0 mmol/L** 或尿酮 2+；**pH < 7.3 和／或 HCO₃⁻ < 18**}}
- {{o|**HHS**：血糖 **≥ 600**；有效滲透壓 **> 300**（2Na + 葡萄糖/18）或總滲透壓 > 320；β-OHB < 3.0；**pH ≥ 7.3 且 HCO₃⁻ ≥ 15**}}
- DKA 嚴重度：{{o|輕度 pH 7.25～7.30、HCO₃⁻ 15～18；中度 pH 7.0～7.25、HCO₃⁻ 10～15；重度 pH < 7.0、HCO₃⁻ < 10}}

## 治療

### 輸液與胰島素
- {{b|**0.9% NaCl**（嚴重低血容 1 L/h）}}；之後以 {{o|8～12 小時內補足 50% 缺水}}為目標
- {{p|**血糖降到 < 250 mg/dL 時加 5% 或 10% dextrose**}}；euglycemic DKA 一開始就要同時給 dextrose
- 胰島素：
  - {{b|輕度 DKA：皮下速效 0.1 U/kg，再每 1 小時 0.1 U/kg 或每 2 小時 0.2 U/kg}}
  - {{b|中重度 DKA：**IV** 短效胰島素（可先 0.1 U/kg bolus），**0.1 U/kg/h** 持續滴注}}
  - {{b|HHS：IV 0.05 U/kg/h}}

### 電解質
- {{p|**鉀**：一開始常正常或偏高（胰島素缺乏與酸中毒使鉀移到細胞外）；若一開始就低，代表嚴重流失}}；{{o|維持 **4～5 mmol/L**}}
- {{p|**Bicarbonate 只在 pH < 7.0 時才給**}}
- Phosphate：只在肌肉無力、呼吸衰竭、貧血時才補

### 緩解標準
- {{o|DKA：HCO₃⁻ > 18、靜脈 pH > 7.3、血酮 < 0.6 mmol/L}}
- {{o|HHS：滲透壓 < 300、尿量 > 0.5 mL/kg/h、血糖 < 250}}

### 考題重點
- {{r|82 歲意識不清、血糖 525、Na 151、BUN 62、Cr 2.6、BP 98/60（HHS 合併低血容）→ **0.9% normal saline**}}（考106）
- {{r|DKA **錯誤**的：**規律注射基礎胰島素是校正酮酸中毒的重要步驟**}}（考110；應為 IV regular insulin 滴注）

# 低血糖

## 定義與生理

### 重點
- {{p|**Whipple's triad**：1. 符合低血糖的症狀 2. 血糖低 3. 血糖回升後症狀緩解}}
- 反應順序：{{o|血糖約 80～85 mg/dL}} → 胰島素分泌減少 → {{o|約 67 mg/dL}} → 反調節荷爾蒙（**升糖素**、腎上腺素）→ 交感症狀 → 神經性低血糖症狀 → 找食物
- **肝臟與腎臟都能糖質新生**

### 原因
- 有病或用藥的人：
  - {{p|藥物：胰島素或促泌劑、酒精}}
  - 重病：肝、腎、心衰竭、敗血症、營養不良
  - {{p|荷爾蒙缺乏：**cortisol**、升糖素與腎上腺素}}
  - Non-islet cell tumor
- 看似健康的人：
  - {{p|內源性高胰島素：**insulinoma**、NIPHS、**胃繞道術後**、insulin autoimmune hypoglycemia、促泌劑}}
  - 意外、隱瞞或惡意

### Hyperinsulinemic hypoglycemia
- {{p|**72 小時延長禁食試驗（黃金標準）**}}：血糖 {{o|≤ 45 mg/dL}} 時
  - {{g|Insulin ≥ 3 µU/mL + **C-peptide ≥ 0.6** → **內源性**（insulinoma、NIPHS、insulin autoimmune、胃繞道）}}
  - {{g|Insulin ≥ 3 + **C-peptide < 0.6** → **外源性胰島素**}}
- Hypoinsulinemic hypoglycemia：嚴重肝病（肝醣少）、慢性腎病（胰島素分解少、糖質新生少）、重症、**腎上腺功能不足**、酒精

### 考題重點
- {{r|**最不適當**的：**空腹血糖正常值下限是 50 mg/dL**}}（考古，年份未標）
- {{r|會造成低血糖的：**不當使用胰島素或口服藥、胃切除術後、腎上腺機能不足**（答 E：1+3+4）}}（考113）
  - {{g|肢端肥大症、庫欣氏症會造成**高**血糖}}
- {{r|46 歲反覆昏倒、急診血糖 20；空腹 8 小時血糖 76、insulin 2.8、C-peptide 2.2 → 優先：**72 小時延長禁食試驗**}}（考113）

# 糖尿病併發症

## 大小血管併發症

### 重點
- 視網膜病變：成人失明主因；腎病變：ESRD 主因；神經病變：非外傷截肢主因
- {{o|中風與腦血管疾病增加 2～4 倍；8/10 死於心血管事件；壽命減少 5～10 年}}
- {{p|UKPDS：HbA1c 每降 1% → 小血管併發症 **-37%**、心肌梗塞 -14%、糖尿病相關死亡 -21%}}
- {{p|糖尿病病人 CAD 最強預測因子依序：**LDL-C > HDL-C > HbA1c** > 收縮壓 > 吸菸}}

### 併發症篩檢
| 項目 | 頻率 |
|---|---|
| {{p|眼底}} | {{o|T1DM 診斷 **5 年**、T2DM **診斷時**開始；每年；若無視網膜病變可**每二年**}} |
| 足部脈搏、ABI、單股纖維 10 g、128 Hz 音叉、跟腱反射 | {{o|每年}} |
| HbA1c、空腹血糖 | {{o|3 個月}} |
| 血脂 | {{o|每年；藥物治療時 4～6 個月}} |
| {{p|尿白蛋白}} | {{o|T1DM 診斷 5 年、T2DM 診斷時開始；每年；有問題可 3～6 個月}} |
| 肌酸酐、eGFR、尿液、口腔 | {{o|每年}} |

## 糖尿病腎病變

### 治療（ADA）
- {{b|生活型態 + **RAS inhibitor**（有白蛋白尿或高血壓時，用到最大耐受劑量）}}
- {{b|**SGLT2i**（eGFR ≥ 20 開始，持續到透析或移植）± GLP-1 RA}}；再加 nsMRA（finerenone）
- {{b|CCB 或利尿劑達到血壓目標；中高強度 statin}}
- 高血壓：{{o|初始 < 160/100 → 一種藥；≥ 160/100 → 兩種藥}}；{{p|有白蛋白尿 → ACEI 或 ARB}}

## MASLD

### 重點
- 取代 NAFLD
- 定義：脂肪肝 + {{p|至少一個心代謝危險因子}}（前期糖尿病、糖尿病、血脂異常、高血壓），且無大量飲酒或其他原因
- {{o|美國 T2DM 盛行率 > 70%}}
- {{p|**Insulin resistance 扮演核心角色**}}；可由脂肪肝 → MASH → 肝硬化 → 肝癌
- 治療：
  - F0～F1：GLP-1 RA、GIP/GLP-1 dual、pioglitazone、SGLT2i（糖尿病時）
  - F2～F3：GLP-1 RA、dual、pioglitazone；{{b|**resmetirom**（thyroid hormone receptor-β agonist）}}
  - F4 代償肝硬化：謹慎；失代償：只用胰島素

### 考題重點
- {{r|MASLD **錯誤**的：**合併 LDL 高、HDL 低也不宜服用 statin**}}（考114）
  - {{g|正確：resmetirom 已核准用於 MASH 合併 ≥ F2；不宜長期高劑量維生素 E（心血管死亡與出血性中風風險）}}

## 糖胖症

### 考題重點
- {{r|糖胖症**錯誤**的：**運動強度愈高，愈能降低糖尿病發病率與心血管死亡率**}}（考114）
  - 正確：計畫性飲食與運動降低發病率，關鍵是控制體重；中央型肥胖與心血管關係最密切；減掉的主要是脂肪；**LOOK AHEAD 可改善血糖，但沒有降低心血管死亡率**
