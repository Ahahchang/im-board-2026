# 貧血

## 小球性貧血

### 重點
- {{p|**以前 MCV 正常、現在變小 → 缺鐵，不是地中海型貧血**}}
- 地中海型貧血：{{p|**RBC 數偏高、MCV 很低、鐵與 ferritin 正常或高**}}；抹片 target cell
- 缺鐵治療第一線：{{b|**口服 ferrous sulfate**}}

| | α-thalassemia | β-thalassemia |
|---|---|---|
| 染色體 | {{o|16}} | {{o|11}} |
| 基因數 | 4 | 2 |
| Hb 電泳 | {{o|HbA2 < 4%}} | {{p|**HbA2 > 4%**}} |
| HbH stain | {{p|**陽性**}} | 陰性 |
| 嚴重型 | Hb Barts（γ4）→ 胎兒水腫 | Thal major = Cooley's anemia |

### 缺鐵 vs 慢性病貧血（ACD）
| | 缺鐵 | ACD |
|---|---|---|
| 血清鐵 | ↓ | ↓ |
| TIBC | {{p|**高**}} | {{p|**正常或低**}} |
| Ferritin | ↓↓ | 正常或↑ |
| RDW | ↑ | 正常 |
| sTfR | ↑ | 正常 |
| {{p|**Hepcidin**}} | ↓ | {{p|**↑**}} |

### 考題重點
- {{r|40 歲女性、MCV 69.4，5 年前 Hb 12.1、MCV 80.3 → **缺鐵性貧血**}}（考112、考114，答 B）
- {{r|33 歲 RBC 5.51 M、Hb 9.3、抹片 target cell → **地中海型貧血**}}（考114，答 D）
- {{r|25 歲 MCV 68、RBC 4.43 M、ferritin 185、iron 145 → **地中海型貧血**}}（考110，答 C）
- {{r|25 歲女性 ferritin 1.75 → 第一線：**口服 ferrous sulfate**}}（考113，答 A）
- {{r|ACD **不符合**：**hepcidin 產生減少**}}（考109，答 E；應為增加）
- {{r|MCV 75、ferritin 78、iron 41、TIBC 230 → **慢性病貧血**}}（考108，答 C）
- {{r|MCV 69、以前 88 → 最有幫助：**血清鐵**}}（考108，答 B）

| | 葉酸 | B12 |
|---|---|---|

| {{p|**Methylmalonic acid**}} | 正常 | {{p|**↑**}} |

## 溶血與 PNH

### 溶血部位
- {{g|**血管內**：破碎紅血球、溶血性輸血反應、**PNH**、**陣發性冷血紅素尿**、G6PD 缺乏、感染（瘧疾、梭菌）、化學物、熱傷害}}
- {{g|**血管外**：膜缺陷（HS、HE、PNH）、代謝缺陷（G6PD、PK）、免疫藥物感染、HUS、異常血紅素}}
- 溶血表現：貧血、網狀紅血球↑、LDH↑、間接膽紅素↑、血紅素尿（血管內）、球形紅血球
- {{b|**Osmotic fragility test**}}：球形紅血球的表面積/體積比小 → 在較高濃度食鹽水就破

![溶血依破壞部位分類](img/1dqkmyVmsyg4G37adSRQU9UqAw6HbfDGN/p012.webp)

### PNH 重點
- {{p|**PIG-A 突變**；缺 **CD55、CD59**（不是 CD56、CD58）}}
- 血管內溶血 → {{p|**haptoglobin 低、LDH 高、血紅素尿**；因慢性尿中流失鐵 → **可合併缺鐵**}}
- {{p|**靜脈栓塞傾向**}}；{{b|**C5 抑制劑（eculizumab）**}}有效
- {{p|**不會有膽紅素尿**}}（間接膽紅素不從尿排出）

### 考題重點
- {{r|新診斷 PNH 可能出現：**reticulocytosis、缺鐵、血紅素尿**}}（考113，答 C）
- {{r|PNH **錯誤**：**Bilirubinuria**}}（考108、考111）
- {{r|PNH **錯誤**：**紅血球失去 CD55 與 CD56**}}（考110；應為 CD59）

## 再生不良性貧血

### 重點
- {{b|**≤ 40 歲：HLA 相合手足移植；> 40 歲：ATG + cyclosporine**}}
- {{b|**Eltrombopag**}}：加入 ATG + cyclosporine 可提高反應；免疫抑制反應不佳時也可用
- {{p|類固醇、雄性素不是標準治療}}

### 考題重點
- {{r|63 歲、骨髓極度細胞減少 → **ATG**}}（考114，答 B）
- {{r|53 歲 SAA，除控制感染外有幫助：**ATG + cyclosporine + eltrombopag**}}（考112，答 C；IVIG 沒用）
- {{r|55 歲骨髓細胞 10% → **cyclosporine + ATG**}}（考109，答 C）
- {{r|63 歲 SAA，ATG + cyclosporine 反應不佳仍需輸血 → **eltrombopag**}}（考108，答 A）
- {{r|B 肝肝硬化 PLT 67,000 → 最常見原因：**脾功能亢進**}}（考97）

# 骨髓惡性疾病

## MDS

### 考題重點
- {{r|75 歲、芽細胞 9%、複雜核型 → **azacitidine**}}（考109，答 D）
- {{r|Azacitidine 機轉：**DNA methylation inhibitor**}}（考102）；RARS 相關：**SF3B1**（考105）

## 多發性骨髓瘤

### 重點
- {{g|**Myeloma-defining events：SLiM CRAB**}}——高血鈣、腎功能不全、貧血、骨病變；骨髓漿細胞 ≥ 60%、游離輕鏈比 ≥ 100、MRI > 1 處病灶
- {{p|**蛋白尿不是** myeloma-defining event}}
- {{o|**Smoldering MM：M 蛋白 ≥ 3 g/dL 或骨髓漿細胞 10～60%**，無 CRAB}}
- {{b|**Daratumumab = anti-CD38**}}（isatuximab 也是）；elotuzumab = anti-SLAMF7
- ISS：{{p|**albumin + β2-microglobulin**}}；骨掃描沒用（純溶骨性）

### 考題重點
- {{r|Myeloma-defining events 的**例外**：**蛋白尿**}}（考113，答 D）
- {{r|Daratumumab 機轉：**anti-CD38 抗體**}}（考109、考112）
- {{r|75 歲 IgG kappa 3,700 mg/dL、骨髓漿細胞 35%、無 CRAB → **smoldering MM**}}（考108，答 B）

## CLL

### 重點
- {{p|**無症狀、早期（Rai 0～II）→ watchful waiting**}}
- 治療指標：進行性骨髓衰竭（貧血、血小板低）、巨大脾臟或淋巴結、淋巴球快速倍增、B 症狀、自體免疫血球減少對類固醇無效
- {{b|**Ibrutinib = BTK 抑制劑**}}（健保：17p 缺損或復發）；{{b|**venetoclax = BCL-2 抑制劑**}}

### 考題重點
- {{r|70 歲 CLL、淋巴結 2～3 cm、脾一指幅、Hb 13.2、PLT 165 k、無不適 → **watchful waiting**}}（考114，答 E）
- {{r|Ibrutinib 機轉：**BTK 抑制劑**}}（考108、考111）

## 急性白血病

### AML（2022 ELN）
| 風險 | 異常 |
|---|---|
| {{p|**好**}} | {{p|**t(8;21) RUNX1::RUNX1T1、inv(16)/t(16;16) CBFB::MYH11、NPM1 突變（無 FLT3-ITD）**}}、bZIP CEBPA 突變 |
| 中 | NPM1 合併 FLT3-ITD、t(9;11) |
| {{p|**差**}} | {{p|**t(6;9) DEK::NUP214、t(9;22)、inv(3)/t(3;3) GATA2::MECOM（EVI1）**、−5/5q−、−7、17p、複雜核型、**TP53**、ASXL1、RUNX1 等突變}} |

- {{p|**APL t(15;17) PML::RARA 預後好**}}
- FLT3-ITD：{{b|**7+3（anthracycline + cytarabine）+ midostaurin**}}
- {{b|**Venetoclax（BCL-2）**}}：用於不適合強化療的老年 AML（健保）

### ALL
- Ph+ ALL（BCR::ABL1）：{{p|**成人比兒童常見**、t(9;22)、B 細胞（**不表現 CD3**）}}；{{b|dasatinib + 異體移植}}
- {{b|**Inotuzumab ozogamicin = anti-CD22**}} → B-ALL

![APL 抹片：前骨髓細胞](img/1dqkmyVmsyg4G37adSRQU9UqAw6HbfDGN/p046.webp)

### 考題重點
- {{r|Ph+ ALL **錯誤**：**ALL 細胞表面有 CD3**}}（考114，答 B）
- {{r|AML 預後較差：**t(6;9)、t(9;22)、inv(3)、TP53 突變全部**}}（考114，答 E）
- {{r|2022 分類預後最差：**inv(3)/GATA2::MECOM**}}（考113，答 D）
- {{r|預後較好：**t(8;21)、inv(16)、APL t(15;17)**}}（考112，答 D）；t(6;9) 屬差
- {{r|預後很差，**例外**：**NPM1 突變且無 FLT3-ITD**}}（考111，答 C）
- {{r|Inotuzumab（anti-CD22）用於：**B 細胞急性淋巴芽細胞白血病**}}（考110，答 B）
- {{r|57 歲 AML 有 FLT3-ITD → **anthracycline + cytarabine + midostaurin**}}（考109，答 B）
- {{r|Venetoclax 機轉：**BCL-2 抑制劑**}}（考110）
- {{r|抹片如圖 → **急性前骨髓細胞白血病**}}（考108，答 C）

# 淋巴瘤

### 重點
- {{g|**鼻腔腫瘤、cytoplasmic CD3+、CD56+、CD20−、EBER+ → NK/T 細胞淋巴瘤**}}
- {{p|**Double-hit DLBCL：MYC + BCL2 重組**}}，預後很差
- {{p|**Sjögren syndrome 最容易發生淋巴結外淋巴瘤**}}（MALT lymphoma）
- 無症狀、低腫瘤負擔的 follicular lymphoma → {{b|**watchful waiting**}}
- 胃 MALT、H. pylori 陽性、侷限 → {{b|**除菌**}}
- {{g|**Rituximab 是 anti-CD20**（不是 CD19）}}
- 染色體：{{p|**FL t(14;18)、Burkitt t(8;14)、mantle cell t(11;14)**}}

### 考題重點
- {{r|自體免疫疾病最易發生淋巴結外淋巴瘤：**Sjögren**}}（考114，答 A）
- {{r|48 歲 FL、橫膈上下多處 1～2.5 cm 淋巴結、無症狀、血液正常 → **watchful waiting**}}（考113，答 E）
- {{r|鼻腔腫瘤、CD56+、EBER+ → **NK/T 細胞淋巴瘤**}}（考112，答 A）
- {{r|標靶與標的配對正確：**ipilimumab-CTLA-4、osimertinib-EGFR、atezolizumab-PD-L1、pembrolizumab-PD-1**}}（考112，答 B；rituximab 是 CD20）
- {{r|65 歲胃 MALT、CD20+、H. pylori+ → **除菌**}}（考111，答 A）
- {{r|Double-hit DLBCL：**MYC + BCL2**}}（考109，答 A）
- {{r|配對**錯誤**：**Ibrutinib-多發性骨髓瘤**}}（考109，答 D）
- {{r|染色體配對正確：**FL t(14;18)、Burkitt t(8;14)**}}（考108，答 C；mantle cell 是 t(11;14)）

# 止血與血栓

## 血小板低下

### ITP 與 HIT
- {{p|**PLT > 3 萬、無出血 → 觀察**}}；治療首選{{b|類固醇}}；{{b|**IVIG 對免疫性血小板低下最有效**}}（快速提升）
- ITP 評估：H. pylori、HCV、HIV、自體免疫；{{p|**不一定要做骨髓檢查**}}
- {{o|**HIT：第一次使用 heparin 後 5～10 天**}}

### TMA
- {{p|**Schistocyte + LDH 上升**}}、haptoglobin **下降**
- {{p|**TTP：ADAMTS13 活性下降**；aHUS 的 ADAMTS13 正常}}

### 考題重點
- {{r|32 歲女性 PLT 52,000、只有手臂瘀青、無黏膜出血 → **密切觀察追蹤**}}（考113，答 E）
- {{r|HIT 最常出現時間：**5～10 天**}}（考111，答 C）
- {{r|IVIG 最有效：**免疫性血小板低下**}}（考110，答 C）
- {{r|35 歲 PLT 36,000、無其他出血 → 最**不需要**：**骨髓檢查**}}（考110，答 E）
- {{r|34 歲 PLT 12,000、只有紫斑 → **口服類固醇**}}（考108，答 B）
- {{r|TMA 最正確：**出現 schistocytes 與高 LDH**}}（考114，答 C）

## 凝血檢驗異常

### aPTT 延長的原因
- **血友病、APS、heparin、vWD**、後天因子抑制物
- {{p|**Factor XIII 缺乏 PT、aPTT 都正常**}}（要驗 clot solubility 或 XIII 活性）

### 後天血友病 A
- {{p|**Factor VIII 抑制物**（自體免疫）}}；PT、thrombin time 正常
- {{p|**Mixing test：一開始矯正，37°C 放 2 小時後又延長**}}
- 可用 {{b|aPCC、rFVIIa}}、免疫抑制

### DOAC 對檢驗的影響
![Dabigatran 與 rivaroxaban 對凝血檢驗的影響](img/1dqkmyVmsyg4G37adSRQU9UqAw6HbfDGN/p061.webp)

- {{g|**Dabigatran（IIa 抑制）→ thrombin time 顯著延長**；**rivaroxaban（Xa 抑制）→ anti-Xa 顯著上升**}}

### Warfarin
![Warfarin 使用後各凝血因子下降速度](img/1dqkmyVmsyg4G37adSRQU9UqAw6HbfDGN/p071.webp)

- {{p|**Factor VII 與 protein C 最先下降**（1～2 天）}}，II 最慢 → 開始時可能短暫高凝，需與 heparin 重疊

### 考題重點
- {{r|65 歲後腹腔血腫、aPTT 40、mixing 後 37 → **factor VIII 後天抑制物**}}（考114，答 C）
- {{r|aPTT 延長可能原因，**例外**：**factor XIII 缺乏**}}（考112，答 D）
- {{r|aPTT 延長可能：**血友病、APS、heparin、vWD 全部**}}（考110，答 E）
- {{r|後天血友病 A **錯誤**：**mixing 2 小時後 aPTT 會恢復正常**}}（考108，答 D）

# 輸血醫學

### Cryoprecipitate
- 含：{{p|**fibrinogen、factor VIII、vWF**}}、factor XIII、fibronectin
- 可用於：{{b|**低纖維蛋白原、A 型血友病、vWD**}}；{{p|**不含 factor VII、IX，也不能補白蛋白**}}

### TRALI
- {{p|**捐血者血漿中有抗受血者 HLA（class I/II）或抗嗜中性球抗體**}}
- {{o|**輸血中或輸血後 6 小時內**}}；缺氧、呼吸急促、兩側肺浸潤
- 治療以{{b|支持性療法}}為主，{{p|**類固醇沒有明確效果**}}
- {{p|**用男性或未懷孕女性的血漿可降低風險**}}

### 血小板 ABO 替換
![血小板 ABO 血型替換原則與血品保存條件](img/1dqkmyVmsyg4G37adSRQU9UqAw6HbfDGN/p078.webp)

- {{o|紅血球 1～6°C 存 35 天；血小板 20～24°C 搖動保存 5 天；血漿 −18°C 一年}}
- 尿毒症出血：{{b|**desmopressin、estrogen、cryoprecipitate、矯正貧血**}}都有幫助

### 考題重點
- {{r|Cryoprecipitate 含有：**fibrinogen、factor VIII、vWF**}}（考109、考114，答 D）
- {{r|Cryoprecipitate 可用於：**A 型血友病、vWD、低纖維蛋白原**}}（考108、考112、考113，答 D）
- {{r|TRALI **錯誤**：**治療以類固醇為主**}}（考112，答 E）
- {{r|TRALI 正確：**與捐血者抗受血者 HLA class II 抗體有關、胸部 X 光兩側浸潤**}}（考111，答 C）
- {{r|TRALI **錯誤**：**一般發生於輸血後 24 小時**}}（考109，答 B；應為 6 小時內）
- {{r|尿毒症出血可用：**desmopressin、estrogen、cryoprecipitate、矯正貧血**}}（考97，答 E）

# 感染與血液病

### 異體造血幹細胞移植後的感染時序
![異體造血幹細胞移植後各期常見的伺機性感染](img/1dqkmyVmsyg4G37adSRQU9UqAw6HbfDGN/p099.webp)

- {{g|**第一期（移植前～嗜中性球恢復，約 15～45 天）**：嗜中性球低下、黏膜破損 → **革蘭陰性桿菌、革蘭陽性菌、HSV、Candida、Aspergillus**}}
- {{g|**第二期（至第 100 天）**：細胞免疫缺陷 → **CMV**、Aspergillus、Pneumocystis}}
- {{g|**第三期（100 天以後）**：B 細胞與 CD4 恢復慢 → **有莢膜細菌（S. pneumoniae、H. influenzae、N. meningitidis）**、VZV、Aspergillus、Pneumocystis、EBV PTLD}}
- {{b|**TMP-SMX 預防**}}：Pneumocystis、Toxoplasma、Nocardia、Listeria、部分 S. pneumoniae；{{p|**對 Pseudomonas 無效**}}

### 考題重點
