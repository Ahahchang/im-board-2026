# 貧血

## 貧血的初步判讀

### 網狀紅血球
- Reticulocytosis 的原因：{{p|**出血、溶血、營養性貧血治療中**（IDA、巨母紅血球性貧血）}}
- Reticulocyte index = retic% × (Hct / 45) ÷ maturation correction
- Maturation correction：{{o|Hct 36～45 → 1.0；26～35 → 1.5；21～25 → 2.0；≤ 20 → 2.5}}
- {{o|**RI < 2 → 製造不足；RI > 2 → 流失或破壞**}}（正常人 1～2）

### 紅血球指數
- {{g|MCV = Hct / RBC；MCH = Hb / RBC；MCHC = Hb / Hct}}
- 大球性貧血第一步：{{p|**先驗 reticulocyte**}}

### 考題重點
- {{r|Hb 9、Hct 30%、retic 3%、白血球血小板正常 → **急性出血性貧血**}}（考88、考96）
- {{r|Hb 10.2、MCV 120 → 找原因最有幫助：**reticulocyte**}}（考93）
- {{r|20 歲女性、RI 1.24、MCV 70 → **輕度地中海型貧血**}}（考84）

## 小球性貧血

### 鑑別
| | 缺鐵性貧血 | 慢性發炎 | 地中海型貧血 |
|---|---|---|---|
| 抹片 | 小、低色素，{{p|大小不一}} | 正常或小 | 小、低色素、**target cell**，{{p|大小一致}} |
| 血清鐵 | {{o|< 30}} | {{o|< 50}} | 正常或高 |
| TIBC | {{o|**> 360**}} | {{o|**< 300**}} | 正常 |
| 飽和度 | {{o|< 10%}} | {{o|10～20%}} | {{o|30～80%}} |
| Ferritin | {{o|**< 15**}} | {{o|30～200}} | {{o|50～300}} |
| 血紅素電泳 | 正常 | 正常 | 異常（β） |

- IDA：{{p|**出血是最重要原因，要注意腸胃道惡性腫瘤**}}；transferrin receptor **上升**；可有**輕度血小板增多**
- 慢性病貧血：transferrin receptor 下降
- 地中海型貧血：{{p|MCV 相對更低、**RBC 數偏高**、**RDW 較低**}}；常有輕度溶血
- {{g|**α-thalassemia**：HbH 陽性，多為**基因缺失**；只缺一個基因 = silent carrier}}
- {{g|**β-thalassemia**：**HbA2 > 3.5%**，多為**基因點突變**}}
- 治療：trait 不需治療；major → {{b|輸血 + 排鐵劑}}，或 {{b|造血幹細胞移植（可治癒）}}
- {{p|**以前 MCV 正常 → 排除先天的地中海型貧血，優先想 IDA**}}
- 鐵在十二指腸吸收（需胃酸還原為二價鐵）；B12 在迴腸末端；葉酸在空腸

![地中海型貧血抹片：與淋巴球相比紅血球偏小、大小一致](img/19lFAHV0yy_fmmMo5Wzqw1Dkf7QU2uVHM/p006a.webp)

![缺鐵性貧血抹片：紅血球大小不一、中央淡染區變大](img/19lFAHV0yy_fmmMo5Wzqw1Dkf7QU2uVHM/p006b.webp)

### 考題重點
- {{r|最不會造成 IDA 的：**地中海型貧血**}}（考102；反而易鐵過量）
- {{r|MCV 小、retic 3.5%、間接膽紅素上升、抹片小紅血球 → **地中海型貧血**}}（考106）
- {{r|抹片紅血球大小不一 → **缺鐵性貧血**}}（考94）
- {{r|5 年前 MCV 88，現在 70 → **缺鐵性貧血**}}（考91、考101、考104）；診斷最有幫助：**血清鐵**（考107）
- {{r|MCV 70、鐵與 ferritin 正常、血紅素電泳正常 → **α 型地中海型貧血**}}（考89）
- {{r|IDA 可出現：**小球性貧血 + 輕度血小板增多**}}（考98）

## 大球性貧血

### 原因
- Reticulocytosis（溶血、出血）
- 巨母紅血球性貧血（常**全血球減少**）
- 非巨母紅血球：**肝病、MDS、甲狀腺低下、酒精**

### 巨母紅血球性貧血
- 抹片：{{p|**macro-ovalocyte、嗜中性球核分葉過多**}}、全血球減少
- **骨髓內溶血**：LDH 高（**LDH1** 為主）、間接膽紅素上升
- {{p|Homocysteine 兩者都高；**methylmalonic acid 只有 B12 缺乏才高**}}
- {{p|**神經症狀只見於 B12 缺乏**}}：周邊神經、脊髓**後柱與側柱**、大腦
- 多數為 B12 缺乏：**惡性貧血**（anti-IF Ab、anti-parietal cell Ab）；{{b|終身注射 B12}}
- Schilling test：評估 intrinsic factor 缺乏
- {{g|**B12 來自動物性食物；葉酸來自綠葉蔬菜**}}
- {{g|**全胃切除 → 缺鐵 + 缺 B12**}}（缺胃酸與 intrinsic factor）

### 考題重點
- {{r|可造成全血球減少：**B12 缺乏、MDS、肝硬化、自體免疫疾病**}}（考103，答 E）
- {{r|B12 正確：**自體免疫萎縮性胃炎缺內因子、吸收後分布到肝骨髓神經、缺乏造成巨母紅血球貧血與舌炎感覺異常**}}（考91）；{{p|在**迴腸**吸收，蔬菜中不含}}
- {{r|全胃切除易發生：**缺鐵 + B12 缺乏**}}（考89）
- {{r|**不是**小球性的：**葉酸缺乏**}}（考87）
- {{r|葉酸缺乏巨母紅血球貧血的特點：**舌乳頭萎縮**}}（考84）
- {{r|MCV 115、retic 0.5%、全血球低、LDH 高 → **酒精性葉酸缺乏、惡性貧血、全胃切除 B12 缺乏**}}（考99，答 D）

## 溶血性貧血

### 表現
- Hb 急降、**reticulocytosis**、**間接膽紅素上升**、{{p|**LDH 上升（LDH2 為主）**}}、{{p|**haptoglobin 下降**}}
- 血管內溶血：血漿血紅素、methemalbumin、**尿 hemosiderin**、{{p|**尿潛血陽性但沉渣沒有紅血球**}}

### 血管內 vs 血管外
- {{g|**血管內**：PNH、**ABO 不合輸血**、**機械瓣膜**、G6PD 缺乏、冷抗體 AIHA（IgM）}}
- {{g|**血管外**：球形紅血球（hereditary spherocytosis）、溫抗體 AIHA（IgG）、紅血球寄生蟲}}
- {{p|紅血球內在缺陷都是先天的，**唯一例外是 PNH**；外在因素都是後天的，例外是 familial atypical HUS}}

### 自體免疫溶血（AIHA）
- **Coombs test**：DAT 測紅血球上的抗體；IDAT 測血清抗體（DAT 陰性、IDAT 陽性 → 同種抗體）
- DAT anti-IgG+：penicillin、methyldopa；DAT anti-C3+：**cold agglutinin disease**、PCH；兩者皆+：warm AIHA、fludarabine
- 找潛在自體免疫疾病或淋巴惡性腫瘤
- 治療：{{b|**類固醇**}}、需要時少量輸血、脾切除、plasma exchange、細胞毒性藥物、danazol

### 遺傳性球形紅血球症
- 細胞膜骨架缺陷；{{p|**MCHC 高**}}、MCV 偏低；抹片紅血球**失去中央淡染區**
- 診斷：{{b|**osmotic fragility test**}}
- 治療：{{b|脾切除}}，{{p|最好延到 **10 歲以後**（避免嚴重敗血症）}}

![遺傳性球形紅血球症抹片](img/19lFAHV0yy_fmmMo5Wzqw1Dkf7QU2uVHM/p014.webp)

### PNH（陣發性夜間血紅素尿症）
- {{p|後天的造血幹細胞**體細胞突變**（**PIG-A** 基因，X 染色體）→ GPI anchor 缺失}}
- 三大表現：{{p|**血管內溶血、靜脈栓塞（約 40%，腹痛、Budd-Chiari、少見部位）、骨髓低下**}}
- 診斷：{{b|**flow cytometry：CD55（DAF）與 CD59（MIRL）缺失**}}；舊法 sugar water test、Ham's test
- {{p|**LAP score 低**}}（與 CML 相同）
- 治療：{{b|**Eculizumab（anti-C5）**}}，改善溶血與輸血需求，但不能治癒；不再需要 washed RBC
- {{g|Coombs 陰性的溶血 → 想到 PNH}}

![PNH 病人的深色尿](img/19lFAHV0yy_fmmMo5Wzqw1Dkf7QU2uVHM/p015.webp)

### 機械性溶血
- March hemoglobinuria（馬拉松）
- **人工心臟瓣膜**（尤其瓣周逆流）→ 微血管病變溶血，抹片見**破碎紅血球**

![機械瓣膜病人抹片：破碎紅血球](img/19lFAHV0yy_fmmMo5Wzqw1Dkf7QU2uVHM/p017.webp)

### 考題重點
- {{r|急性溶血通常有：**網狀紅血球增加 + 膽紅素增加**}}（考87）
- {{r|抹片可見有核紅血球與網狀紅血球 → **溶血性貧血**}}（考105）
- {{r|**不屬於**血管內溶血的：**遺傳性球形紅血球症**}}（考88）
- {{r|SLE 最需要大量類固醇的：**溶血性貧血 Hb 6**}}（考96）
- {{r|23 歲男性當兵體檢輕微貧血與黃疸、抹片球形紅血球 → **hereditary spherocytosis**}}（考101）
- {{r|溶血、Coombs 陰性、尿潛血陽性但沒有紅血球 → **flow cytometry 驗 CD55、CD59**}}（考102、考107）
- {{r|PNH **錯誤**：**紅血球膜上 DAF 增加**}}（考84；應為減少）
- {{r|溶血、MCV 95 → 最**不需要**的：**osmotic fragility test**}}（考98）
- {{r|Eculizumab 效果好的：**PNH**}}（考99）；適應症還有 aHUS、重症肌無力
- {{r|二尖瓣置換後、LDH 4300 → **機械性溶血**}}（考100）
- {{r|PNH 正確：**全血球減少、易靜脈栓塞、Eculizumab 可改善症狀**}}（考101，答 C）

## 再生不良性貧血（AA）

### 重點
- {{p|骨髓**細胞少**的全血球減少}}（巨母紅血球性貧血則是骨髓細胞多）
- {{o|**Severe AA：ANC < 500、PLT < 20,000、網狀紅血球 < 20,000，三項符合兩項**}}
- 病因：特發性、放射線、**藥物（chloramphenicol）**、化學物（benzene）、**病毒（Parvovirus B19）**、自體免疫、PNH、懷孕
- 治療：
  - {{b|**≤ 40 歲：HLA 相合手足的造血幹細胞移植**}}
  - {{b|**> 40 歲：ATG + cyclosporine**}}
  - {{p|**類固醇無效**}}
  - 免疫抑制失敗又不能移植：{{b|eltrombopag（TPO agonist）}}
- {{p|沒有出血就不用輸血小板}}；有黏膜出血、明顯出血或 {{o|PLT < 5,000～10,000}} 才輸
- {{p|**不要輸親屬捐的血小板**}}（日後移植會被致敏）
- AA 移植後長期無病存活率最高（不是惡性病）

### 考題重點
- {{r|17 歲 SAA → **HLA 相合手足的異體移植**}}（考103）
- {{r|55 歲 SAA、PLT 21,000 → **ATG + 輸紅血球**}}（考92、考96，答 A）
- {{r|25 歲 SAA、嗜中性球低發燒 → **培養後給廣效抗生素 + 找 HLA 相合手足移植**}}（考89，答 E）
- {{r|19 歲 SAA、無出血 → 最不需要：**輸血小板**}}（考104）
- {{r|移植後吃 cyclosporine、溶血、血小板低、Cr 上升 → **cyclosporine 引起的微血管病變**}}（考99）
- {{r|57 歲 SAA → **ATG + cyclosporine**}}（考100）

## 紅血球增多症

### 診斷流程
- Hct 上升 → 測 RBC mass（正常 → 相對性）→ 測 **EPO**
- {{p|**EPO 低 → PV → 驗 JAK2**}}
- EPO 高 → 測動脈血氧：低 → 心肺疾病（COPD、高海拔、分流）；正常 → 查 carboxyhemoglobin（抽菸）、高親和力血紅素、**分泌 EPO 的腫瘤**
- {{g|分泌 EPO 的腫瘤：**腎細胞癌或囊腫、小腦血管母細胞瘤、子宮肌瘤、肝癌**}}

### 考題重點
- {{r|長期肺病、Hb 18.6 → 區分 PV 與次發性：**ABG、JAK2、EPO 都有幫助**}}（考102）
- {{r|最不可能造成紅血球增多：**甲狀腺亢進**}}（考98）

# 白血球疾病

## 細胞化學染色與表面標記

### 染色
- {{g|**PAS → 淋巴系；MPO（peroxidase）、CAE → 骨髓系；NSE → 單核球系**}}
- {{p|**LAP score 低：CML、PNH**}}

### 表面抗原
| 細胞 | 標記 |
|---|---|
| 骨髓系 | **CD13、CD33** |
| 巨核細胞 | **CD41、CD61** |
| B 細胞 | CD10、CD19、CD20 |
| T 細胞 | CD3、CD4、CD7、CD8 |
| 造血幹細胞 | CD34 |

### 染色體變化
| 疾病 | 變化 |
|---|---|
| CML | {{p|**t(9;22)**，BCR-ABL（p210）}} |
| ALL | {{p|t(9;22)（p190）→ **預後差**}} |
| AML M2 | {{p|t(8;21)，RUNX1-RUNX1T1 → **預後好**}} |
| APL（M3） | {{p|**t(15;17)，PML-RARα** → 預後好}} |
| AML M4eo | {{p|**inv(16)**，CBFB-MYH11 → 預後好}} |
| Burkitt lymphoma | t(8;14)，**MYC** |
| Follicular lymphoma | {{p|**t(14;18)，BCL-2**（抗凋亡）}} |
| Mantle cell lymphoma | t(11;14)，**cyclin D1** |

### 考題重點
- {{r|LAP 降低：**CML**}}（考87、考88）
- {{r|PV **錯誤**：**LAP 常下降**}}（考100；PV 的 LAP 是上升）
- {{r|Peroxidase 陰性、cytoplasmic CD3+、CD7+ → **急性 T 淋巴細胞白血病**}}（考90）
- {{r|芽細胞 45%、MPO 陰性、NSE 陰性、CD13+、CD33+ → **AML M0**}}（考92）
- {{r|CD41+、CD61+ → **急性巨核細胞白血病**}}（考101）
- {{r|幫忙診斷 follicular lymphoma：**t(14;18) + BCL-2 異常表現**}}（考103，答 B）
- {{r|急性白血病預後較好：**AML t(15;17)**}}（考88，答 D）

## 急性骨髓性白血病（AML）

### 診斷與預後
- {{o|**骨髓芽細胞 ≥ 20%**}}（WHO）；看到 **Auer rod** 就是 AML
- 預後看年齡與細胞遺傳

| 風險 | 細胞遺傳 | 分子 |
|---|---|---|
| 好 | {{p|**inv(16)、t(16;16)、t(8;21)、t(15;17)**}} | {{p|核型正常 + **NPM1 突變且無 FLT3-ITD**；雙對偶 CEBPA 突變}} |
| 中 | 核型正常、t(9;11) | t(8;21)、inv(16) 合併 c-KIT 突變 |
| 差 | {{p|**複雜核型（≥ 3）、monosomal、−5、5q−、−7、7q−、17p 異常**}}、11q23（非 t(9;11)）、inv(3)、t(6;9)、t(9;22) | {{p|核型正常 + **FLT3-ITD**}} |

### 治療
- 誘導：{{b|**7+3：Ara-C 7 天 + daunorubicin 或 idarubicin 3 天**}}
- 緩解後：好的 → {{b|高劑量 Ara-C 鞏固}}或自體移植；差的 → {{b|**異體移植**}}
- FLT3 突變：{{b|midostaurin（健保）、gilteritinib、quizartinib}}，可加入誘導治療
- 單核球性（M4/M5）：{{p|**牙齦、皮膚浸潤**、中樞神經侵犯}}

![AML 骨髓：myeloblast 與 Auer rod](img/19lFAHV0yy_fmmMo5Wzqw1Dkf7QU2uVHM/p027.webp)

### 考題重點
- {{r|預後最差：**−7**}}（考104）
- {{r|預後較好：**NPM1 突變、CEBPA 突變**}}（考100，答 C）
- {{r|inv(16) AML 緩解後 → **高劑量 Ara-C 鞏固**}}（考94）
- {{r|骨髓圖見 Auer rod → **AML**}}（考99）
- {{r|化療後 PLT 3,000 → **經白血球去除的血小板濃縮液**}}（考93）

## 急性前骨髓細胞白血病（APL，M3）

### 重點（{{r|超愛考}}）
- {{p|**DIC**}}、常白血球低；**t(15;17)、PML-RARα**
- 抹片：{{g|**一綑一綑的 Auer rod（faggot cell）**}}
- 治療：{{b|**ATRA + ATO（arsenic trioxide）**}}，治癒率高
  - {{o|低風險（WBC < 10,000、PLT > 40,000）：ATRA + ATO}}
  - {{o|高風險（WBC > 10,000）：idarubicin + ATRA ± ATO}}
- 追蹤微量殘存疾病：{{b|**PML-RARA**}}
- 緩解後：鞏固 + ATRA 或低劑量化療維持；{{p|不需異體移植}}

### 分化症候群（retinoic acid syndrome）
- {{o|治療**前 3 週**內}}；ATO 也會
- {{p|**發燒、呼吸困難、胸痛、肺浸潤、肋膜與心包膜積液、低血氧**}}、水腫
- {{b|**最優先：類固醇（dexamethasone）**}}；{{o|死亡率約 10%}}
- ATRA 其他副作用：肝功能異常、皮膚嘴唇乾燥

![APL 分化症候群：兩側肺浸潤](img/19lFAHV0yy_fmmMo5Wzqw1Dkf7QU2uVHM/p030.webp)

### 考題重點
- {{r|APL 正確：**多有 t(15;17)、有 PML-RARα、ATRA 可緩解**}}（考89、考90）
- {{r|Retinoic acid syndrome 常見：**發燒 + 肺浸潤呼吸急促**}}（考91，答 C）
- {{r|最迫切有效：**corticosteroid**}}（考93）；第 12 天腳腫呼吸急促發燒 → **dexamethasone**（考96）
- {{r|ATRA 最少出現的副作用：**周邊神經病變**}}（考94）
- {{r|APL 緩解後：**鞏固化療 + tretinoin 或低劑量化療維持**}}（考95）

## 骨髓增生性腫瘤（MPN）

### 真性紅血球增多症（PV）
- {{p|**JAK2 V617F > 90%**}}（其餘為 exon 12）
- 表現：Hb 高、**白血球與血小板增多**、輕中度脾腫大、痛風、**皮膚癢**、**栓塞**
- 與次發性鑑別：{{p|**PaO2 正常、EPO 低 → PV**}}
- 治療：{{b|**定期放血**（維持缺鐵狀態）}}

### 原發性血小板增多症（ET）
- {{o|血栓 60%、出血 40%}}（血小板功能異常）
- 與反應性鑑別：IDA、慢性感染或發炎
- 突變：{{p|**JAK2 > CALR > MPL**}}
- 治療：{{b|低劑量 aspirin}}；高風險（{{o|≥ 60 歲}}、曾血栓或大出血、{{o|PLT ≥ 150 萬}}）加 {{b|hydroxyurea 或 anagrelide}}

### 原發性骨髓纖維化（PMF）
- 巨核細胞分泌 PDGF、TGF-β → 纖維化
- 治療：{{b|**ruxolitinib（JAK1/2 抑制劑）**}}

### 2016 WHO 診斷
- PV：{{o|Hb 男 > 16.5、女 > 16.0（或 Hct 男 > 49%、女 > 48%）}}、骨髓三系增生、JAK2 突變；次要：**EPO 低**
- ET：{{o|**PLT ≥ 450 k**}}、巨核細胞增生、排除其他、JAK2/CALR/MPL 突變
- PMF：巨核細胞增生不典型伴纖維化；次要：貧血、WBC ≥ 11,000、脾腫大、LDH 上升、leukoerythroblastosis

### 考題重點
- {{r|PV 較次發性多見的，**例外**：**EPO 高**}}（考105）
- {{r|配對錯誤：**Myelofibrosis：azacitidine**}}（考104；應為 ruxolitinib）
- {{r|PV 最安全有效：**定期放血**}}（考87）
- {{r|PV 90% 以上有：**JAK2 突變**}}（考96）；Hb 17.5、WBC 與 PLT 高、JAK2 → **PV**（考97）；EPO 低 → **驗 JAK2**（考99）
- {{r|血小板升高鑑別，**例外**：**PNH**}}（考90）
- {{r|門脈栓塞 + JAK2 → **MPN**}}（考101）
- {{r|PLT 73 萬、無 JAK2 → 最有幫助：**CALR 突變**}}（考103）
- {{r|42 歲 PLT 89.6 萬、JAK2 → 講義答 **observation**}}（考107）；{{p|講義說明此題選項都不理想，應給**低劑量 aspirin**}}

## 淋巴瘤

### Hodgkin vs NHL
| | Hodgkin | NHL |
|---|---|---|
| 表現 | 多在淋巴結 | 淋巴結外較多 |
| 擴散 | {{p|**連續性淋巴結擴散**}} | 血行、跳躍式 |
| 縱膈腔 | 常見 | 少見（lymphoblastic 除外） |
| 脾臟 | 常見 | 較少 |
| 肝、骨髓、腸胃、中樞 | 少見 | 常見 |

### Ann Arbor 分期
- I：單一淋巴結群；II：橫膈同側多群；III：橫膈兩側；IV：多處淋巴結外
- {{o|X：bulk > 10 cm}}；E：淋巴結外延伸；{{o|B 症狀：體重減輕 > 10%、發燒、盜汗}}

### Hodgkin lymphoma
- IPS：{{o|albumin < 4、Hb < 10.5、男性、≥ 45 歲、第 IV 期、WBC ≥ 15,000、淋巴球 < 8% 或 < 600}}
- 治療：{{b|**ABVD**（doxorubicin、bleomycin、vinblastine、dacarbazine）}}
- 復發或難治：{{b|化療 + 自體移植、**brentuximab vedotin（anti-CD30）**、PD-1 抑制劑}}

### NHL 的 IPI
- {{g|口訣 **APLES**：**A**ge > 60、**P**erformance status ≥ 2、**L**DH 上升、**E**xtranodal > 1 處、**S**tage III/IV}}
- {{o|5 年存活：低（0～1）73%、低中（2）51%、高中（3）43%、高（4～5）26%}}

### 依惡性度
- **低度（indolent）：follicular lymphoma**——{{p|即使晚期也慢性，**化療無法治癒**}}，常先觀察；有做化療時加 {{b|rituximab}} 有存活好處
- **中高度：DLBCL**——不治療進展快；{{b|**R-CHOP**}}，{{o|治癒率約 70%}}；分為 germinal center 與 non-GC（activated B-cell）型；{{p|double hit：MYC + BCL-2}}
- **極高度：Burkitt**——當作急性白血病治療（hyper-CVAD、CODOX-M/IVAC），易 TLS
- **Adult T-cell leukemia/lymphoma**：{{p|**HTLV-I**}}、**幸運草狀細胞核**、高血鈣、皮膚浸潤
- **Gastric MALT lymphoma**：{{p|**H. pylori** 相關，除菌可緩解}}；IPSID 也對抗生素有反應
- **Hairy cell leukemia**：脾腫大、全血球減少、骨髓**乾抽**；{{p|**TRAP 染色陽性**}}；{{b|cladribine 一個療程}}緩解率高
- {{p|T 細胞淋巴瘤**較常**侵犯淋巴結外}}

- {{r|MM 表現：**骨痛、高血鈣、蛋白尿、凝血異常**全部}}（考94）
- {{r|Bisphosphonate 目的：**降血鈣 + 減緩骨破壞**}}（考95）
- {{r|背痛、Ca 12.8、Cr 1.9、globulin 4.5 → **MM**}}（考96）
- {{r|拔牙後下顎骨壞死 → **zoledronic acid**}}（考99）
- {{r|MM 有效：**bortezomib、thalidomide、steroid**}}（考98；bevacizumab 無效）
- {{r|貧血、高血鈣、Cr 2.6、背痛 X 光 → 下一步：**血液與尿液免疫電泳**}}（考100）

## 其他白血球相關

### 藥物引起的血球減少
- 嗜中性球低下：{{b|**phenytoin、carbamazepine、ticlopidine（Licodin）、抗甲狀腺藥、chloramphenicol、sulfonamide、penicillin**}}
- 血小板低下：quinidine、rifampin、**heparin**（伴血栓）
- 自體免疫溶血：**methyldopa**
- {{r|最可能造成嗜中性球低下：**ticlopidine**}}（考91）

### HLH（噬血症候群）
- 病因：溶血性貧血、感染、惡性腫瘤；細胞毒性 T 細胞與巨噬細胞異常活化
- {{p|**發燒、全血球減少、脾腫大**}}；{{p|**ferritin↑、TG↑、fibrinogen↓**}}、LDH↑
- 治療原發病 ± 短期免疫抑制
- {{r|常見：**發燒、全血球減少、高 ferritin、高 LDH**}}（考100，答 E）

### 脾腫大
- 感染：瘧疾、黑熱病、粟粒性 TB、亞急性心內膜炎
- 充血：門脈高壓、心衰竭
- 紅血球疾病：球形紅血球症、地中海型貧血、AIHA
- 浸潤：淋巴瘤、**MPN**、Gaucher、肝醣儲積、類澱粉
- 免疫：AIHA、**Felty syndrome**、SLE
- 脾切除適應症：{{b|**球形紅血球症、hairy cell leukemia、難治 ITP/AIHA、脾功能亢進**}}
- {{p|脾切除後：**血小板與白血球增加、Howell-Jolly body、target cell**}}；{{p|兒童易敗血症}}

### 考題重點
- {{r|同時肝脾腫大，**除了**：**PV**}}（考95）
- {{r|脾腫大可見：**Felty、脾靜脈栓塞、MPN、慢性瘧疾**}}（考92，答 C）；登革熱不會
- {{r|脾切除後常見：**血小板與白血球增加、Howell-Jolly body、兒童易敗血症**}}（考84，答 E）
- {{r|**不會**全血球減少：**脾臟切除後**}}（考87）
- {{r|脾切除**錯誤**：**紅血球形態沒有變化**}}（考88）

## 造血幹細胞移植時機
- AML/ALL：**第一次緩解**（預後好的等第二次緩解）
- CML：加速期與芽細胞期
- MM：自體；年輕高風險考慮異體
- 惡性淋巴瘤：{{p|高惡性度**第一次復發後**}}（chemosensitive relapse），或 IPI 差者於 CR1
- 再生不良性貧血：嚴重型
- {{p|自體移植比異體移植**血球恢復較快**}}；乳癌已不做高劑量化療合併移植
- {{r|最佳時機：**AML 第一次完全緩解**}}（考84）
- {{r|移植後長期無病存活最高：**再生不良性貧血**}}（考87）
- {{r|**錯誤**：**乳癌肝轉移做高劑量化療合併移植治癒率較高**}}（考87）

## 造血生長因子
- EPO：ESRD、MDS、化療引起的貧血
- {{b|G-CSF}}：{{p|加速化療或移植後白血球恢復，**但不延長存活**}}；幹細胞動員
- {{r|G-CSF 正確：**減少化療後白血球低下、減少感染、加速移植後恢復、收集周邊幹細胞**}}（考87，答 D）

# 止血與血栓

## 紫斑 vs 凝血異常
- {{g|**血小板或血管問題：瘀點（petechiae）、立即出血**}}
- {{g|**凝血因子問題：瘀斑、深部血腫、關節出血、延遲性出血**}}
- 老年性紫斑：手背與前臂外側，約兩週自行消失

![老年性紫斑](img/19lFAHV0yy_fmmMo5Wzqw1Dkf7QU2uVHM/p072.webp)

## 凝血檢驗

### 路徑
- 內在路徑：XII、XI、IX/VIII → X/V、II、fibrinogen → {{p|**aPTT**}}
- 外在路徑：tissue factor、VII → X/V、II、fibrinogen → {{p|**PT**}}
- {{p|**維生素 K 依賴因子：II、VII、IX、X**}}（加上 protein C、S）
- {{p|**Factor XII 缺乏不會出血**}}，只有 aPTT 延長
- {{p|**Factor VII 半衰期最短（4～6 小時）**}} → 肝病、warfarin、維生素 K 缺乏**最先 PT 延長**

### 只有 aPTT 延長（PT 正常）
- **血友病 A/B、vWD、factor VIII 抑制物、lupus anticoagulant（APS）、heparin**、factor XII 缺乏

### 只有 PT 延長
- **Factor VII 缺乏**、早期維生素 K 缺乏或 warfarin

### Mixing test
| | 0 小時 | 2 小時 |
|---|---|---|
| 因子缺乏 | 矯正 | 矯正 |
| Lupus anticoagulant | {{p|**不矯正**}} | 不矯正 |
| 因子抑制物（後天血友病） | 矯正 | {{p|**又延長**}} |

### 考題重點
- {{r|正確：**腺癌比上皮癌常見 DIC**}}（考84）
- {{r|PTT 延長但 PT 正常，**例外**：**維生素 K 缺乏**}}（考90）
- {{r|常造成 PTT 延長：**vWD、APS、factor VIII 抑制物、heparin**}}（考93，答 D；TTP 不會）
- {{r|PT 延長、aPTT 正常：**factor VII 缺乏**}}（考97，答 A）
- {{r|PT 與 PTT 都延長，最不可能：**factor XII 缺乏**}}（考103）
- {{r|PT 正常、aPTT 延長：**APS、vWD**}}（考106，答 D）

## 血小板低下

### 一般原則
- {{p|**尿毒症造成血小板功能異常，不是數目減少**}} → 手術前用 {{b|**DDAVP**}}
- 肝硬化脾腫大（脾功能亢進）→ 追蹤即可
- 多數藥物引起的血小板低下 {{o|停藥 7～10 天}}回復

### 考題重點
- {{r|血小板低下機會最小：**尿毒症**}}（考94）
- {{r|PLT 26,000、只有輕微瘀青 → **錯誤**：**需要輸血小板**}}（考92）
- {{r|肝硬化脾腫大 PLT 78,000 → **追蹤，不需治療**}}（考93）

## Heparin 引起的血小板低下（HIT）
- {{p|**抗 PF4/heparin 複合物抗體** → 活化 FcγRIIA}}
- {{o|發生率 0.2～3%}}（產生抗體者 8～50%）
- {{o|**時間：用藥後 5～14 天**}}（抗體約 4 天產生）
- 血小板很少低於 {{o|20,000}}；{{p|**容易併發栓塞**}}；少見：皮膚壞死、雙側腎上腺出血、靜脈性肢體壞疽
- LMWH 發生率較低
- 診斷：**4Ts score**
- 治療：{{b|**停 heparin**，改 argatroban、bivalirudin、fondaparinux、danaparoid、rivaroxaban}}；{{p|**血小板 > 15 萬才能開始 warfarin**}}
- 抗凝時間：{{o|無血栓 4 週；有血栓 3 個月}}
- {{r|HIT **錯誤**：**第一次使用一般 2～3 星期發生**}}（考105）

## 免疫性血小板低下（ITP）

### 重點
- {{p|**排除性診斷**}}（抗血小板抗體檢查不準）
- 骨髓巨核細胞**增加**
- 輸血小板常無效
- {{p|**PLT > 2～3 萬、沒出血、生活品質好 → 不治療**}}
- 緊急：{{b|**危及生命出血 → IVIG**}}
- 第一線：{{b|**prednisolone 1 mg/kg 或 dexamethasone 40 mg × 4 天**}}
- 第二線：{{b|rituximab}}（{{o|反應 63%}}）、{{b|**TPO receptor agonist（romiplostim、eltrombopag）**}}、{{b|脾切除}}（{{o|85% 反應，2/3 持久}}）

### 考題重點
- {{r|25 歲 PLT 18,000、僅皮膚紫斑 → **類固醇，不需輸血小板**}}（考90、考98、考100）
- {{r|PLT 47,000、只有瘀青 → **觀察追蹤**}}（考107）
- {{r|脾切除前最適當：**eltrombopag**}}（考104）
- {{r|Eltrombopag 機轉：**TPO receptor agonist**}}（考106）
- {{r|鑑別血小板低下幫忙最小：**血小板抗體**}}（考106）

## 血栓性微血管病變（TTP/HUS）

### 重點
- TTP：{{p|**ADAMTS13 缺乏** → 超大型 vWF}}
- HUS：常在**血便**後，**E. coli O157:H7**（shiga toxin）
- {{g|**五聯症**：微血管病變溶血、血小板低下、**神經症狀**（TTP）、**腎功能異常**（HUS）、發燒}}（不一定全部出現）
- {{p|**破碎紅血球（schistocyte）+ 血小板低下 + PT/aPTT 正常**}}
- 病因：特發性、SLE、懷孕、癌症、AIDS、藥物（**ticlopidine、mitomycin C、cyclosporine**）
- 治療：{{b|**plasma exchange**}} + {{b|類固醇}}；{{p|**不要輸血小板**}}
- Atypical HUS（補體 C5 活化）：{{b|eculizumab}}
- {{g|**Evans syndrome = AIHA + ITP**}}

![TTP 抹片：破碎紅血球](img/19lFAHV0yy_fmmMo5Wzqw1Dkf7QU2uVHM/p080.webp)

### 考題重點
- {{r|溶血、PLT 23,000、PT/PTT 正常、抹片破碎紅血球 → **TTP**}}（考102）
- {{r|意識混亂、溶血、PLT 11,000 → 有幫助：**plasma exchange + 免疫調節治療**}}（考107，答 D）
- {{r|TTP **不適當**：**常輸注血小板**}}（考89）
- {{r|意識不清、貧血、PLT 30,000、凝血正常 → **TTP**}}（考89）
- {{r|TTP 常見：**schistocyte、ADAMTS13 缺乏、LDH 高、reticulocytosis**}}（考98，答 E）
- {{r|發燒腹痛、意識不清、腎功能差、破碎紅血球 → **plasmapheresis**}}（考87）

## 瀰漫性血管內凝血（DIC）
- 病因：**敗血症、惡性腫瘤（APL、腺癌、攝護腺癌）、產科、重大外傷**
- 凝血失控：{{p|**fibrinogen↓、PT/aPTT 延長、血小板低下**}}、protamine sulfate test（+）
- 纖溶亢進：{{p|**FDP（+）、D-dimer（+）**}}
- {{p|慢性 DIC：PT、aPTT、PLT 可能正常，只有 PST、FDP、D-dimer 陽性}}
- 治療：支持與治療原發病；可補充凝血因子；heparin 有爭議（主要在慢性 DIC）

## 血友病
- {{g|**A：缺 factor VIII；B：缺 factor IX**}}
- {{p|**aPTT 延長，PT、出血時間正常**}}
- 嚴重度：{{o|**< 1% 嚴重、1～5% 中度、5～40% 輕度**}}
- Factor VIII 半衰期 {{o|8～10 小時}} → 手術時{{b|**一天兩次 factor VIII**}}
- {{p|**Cryoprecipitate 含 VIII、vWF、fibrinogen、fibronectin、XIII**，沒有 IX → 對 B 型沒幫助}}
- 有抑制物時：{{b|**porcine VIII**（只能治 A 型）、**rFVIIa（NovoSeven）**、**aPCC（FEIBA）**}}
- 後天血友病 A：{{p|**factor VIII 抑制物**，常見於老人與女性}}

### 考題重點
- {{r|**不正確**：**嚴重 A 型血友病 PT 與 PTT 都延長**}}（考88；PT 正常）
- {{r|A 型血友病膽囊切除 → **factor VIII 一天兩次**}}（考90）
- {{r|有抗 VIII 抗體出血時：**FVIIa、porcine VIII、aPCC 都可以**}}（考96，答 E）
- {{r|Cryoprecipitate 沒有幫助的：**B 型血友病**}}（考91）
- {{r|兩腳瘀青、PT 正常、aPTT 77、mixing 0 小時矯正 1 小時又延長 → **後天血友病**}}（考100、考105）
- {{r|68 歲腹內血腫、aPTT 55、mixing 部分矯正 → **後天血友病**}}（考107）

## 類血友病（vWD）
- vWF：讓血小板黏附內皮、**穩定 factor VIII**
- {{p|**血小板數正常、出血時間延長、aPTT 延長（VIII 低）**}}；vWF Ag 與 **ristocetin cofactor 都下降**
- Type 1 量不足；Type 2 質異常；Type 3 最嚴重
- {{b|**Type 1 用 DDAVP**}}（促使內皮釋出 vWF）；也可用 cryoprecipitate、含 vWF 的 VIII 濃縮劑（Haemate P）
- {{g|年輕女性**經血過多** + 出血時間長 + PTT 延長 → vWD}}

### 考題重點
- {{r|vWD 常見：**血小板功能異常、aPTT 延長、VIII 下降**}}（考104，答 E）
- {{r|vWD **錯誤**：**ristocetin cofactor 正常**}}（考92）
- {{r|vWD type 1 拔牙可用：**DDAVP、cryoprecipitate、Haemate P**}}（考95，答 D；純 recombinant VIII 不含 vWF）
- {{r|26 歲經血過多、出血時間長、PTT 延長 → **vWD**}}（考98）

## 抗凝系統與血栓傾向

### 天然抗凝物質
- Antithrombin III
- **Protein C**：在 protein S 協助下切斷 Va、VIIIa
- APC resistance（**factor V Leiden**）：亞洲極少，西方 DVT 的 50%
- {{p|**Protein S 缺乏是台灣最常見的遺傳性血栓原因**}}

### 病理性抗凝物
- **Lupus anticoagulant**：{{p|**aPTT 延長但不出血**}}，mixing 不矯正；{{p|增加**血栓與流產**}}

### 考題重點

- {{r|台灣最常見的遺傳性血栓缺陷：**protein S 缺乏**}}（考98）

# 輸血醫學

### 減白血球血品的適應症
- 預防**反覆非溶血性發熱反應**
- 預防或延緩**白血球抗原同種免疫**與**血小板輸注無效**
- 預防 **CMV** 傳染

### 放射線照射血品
- {{p|**殺死捐血者淋巴球，預防輸血相關 GVHD（TA-GVHD）**}}
- 用於免疫低下病人、**親屬捐血**

### 血小板輸注
- {{o|台灣捐血中心 2 單位約提升 5,000～10,000/μL}}；分離術血小板約等於 10～12 單位
- {{p|**ABO 不合時，選「捐血者血漿」與「受血者紅血球」相合的血小板**}}（例：A 型血小板給 O 型病人）
- {{g|**血小板的血型選擇剛好與濃縮紅血球相反**}}：缺血時紅血球給 O、血小板給 AB

### 輸血反應
- 急性溶血：**ABO 不合**；延遲性溶血：其他血型抗原
- 非溶血性發熱：捐血者白血球的細胞激素；{{b|**退燒藥預防**}}；{{p|類固醇與抗組織胺無法預防}}；儲存前減白
- **TRALI**：
  - {{p|**捐血者血漿含抗 HLA 或抗嗜中性球抗體**，作用於受血者白血球}}
  - {{o|**輸血中或輸血後 6 小時內**}}；非心因性肺水腫、兩側肺浸潤；{{o|死亡率 5～10%}}
  - 類固醇療效不明確；{{p|英國 2003 年起不用女性捐血者的血漿製 FFP}}

### 鐵沉積
- {{o|每單位紅血球含 200～250 mg 鐵}}；{{o|100 單位約 20 g}}
- 影響內分泌、肝、心臟
- 排鐵劑：{{b|deferoxamine}}（注射、主要經尿排出）、{{b|**deferasirox（Exjade）**}}（口服、主要經膽汁）
- 適應症：重型地中海型貧血、低風險 MDS

### 考題重點
- {{r|胃切除出血 500 mL → **不需要輸血**}}（考87、考92）
- {{r|尿毒症拔牙、出血時間 15 分 → **術前 DDAVP**}}（考89）
- {{r|正確：**免疫低下者血品照射預防 TA-GVHD + 減白可減少發熱反應**}}（考90，答 D）；幹細胞移植不需 ABO 一致
- {{r|AA 牙齦出血 PLT 21,000、要升到 50,000 → **減白血小板 12 單位**}}（考94）
- {{r|血品照射的原因：**預防輸入的血球對宿主產生排斥（GVHD）**}}（考95）
- {{r|TRALI 原因：**輸入血漿含高濃度抗 HLA 抗體**}}（考92）
- {{r|TRALI **錯誤**：**與受血者體內有抗捐血者白血球的抗體有關**}}（考103）；**多在輸血後 6～12 小時發生**（考101）也是錯的
- {{r|A 型病人接受 B 型骨髓移植，第 14 天輸血小板 → **AB 型**}}（考96）
- {{r|預防發熱性非溶血反應：**退燒藥**}}（考98）
- {{r|A 型 MDS、缺 A 型血 → **O 型濃縮紅血球 + AB 型血小板**}}（考99）
- {{r|血鐵沉著症**不正確**：**SAA 比 Cooley's anemia 輸血更頻繁**}}（考93）
