# 講義重點整理格式（給 Claude 用）

每份講義輸出一個 `data/notes/<drive檔案id>.md`。

## Frontmatter（必填）
```
---
id: <Google Drive 檔案 ID>
title: <簡潔標題，去掉副檔名與 (1) 之類的副本標記>
category: <心臟|胸腔|腸胃肝膽|腎臟|內分泌新陳代謝|血液腫瘤|感染|風濕免疫過敏|神經|皮膚|重症急診|綜合其他>
source: <原始檔名>
drive_modified: <Drive 的 modifiedTime，ISO 格式>
summarized: <整理日期 YYYY-MM-DD>
tags: [關鍵主題1, 關鍵主題2, ...]   # 5–12 個，中英文皆可
---
```

## 內文規則
- **完整筆記版**：涵蓋講義幾乎所有考點，讀這份筆記就能取代讀原始講義；不要只寫摘要。
- 階層：`#` 大標（章節／疾病群）→ `##` 中標（疾病）→ `###` 小標（病因、臨床表現、診斷、治療、併發症…）。**每個小標都要有標題**，因為「我的弱點」星號是標在小標上。
- 語言：中文敘述為主，專有名詞、藥名、檢查、縮寫保留英文（例如「HFrEF 首選 ARNI + BB + MRA + SGLT2i」）。第一次出現的縮寫加上全名。
- 條列為主，一行一個考點；可用 2 空白縮排做子項目。
- 比較型內容（鑑別診斷、分期、分類）用表格 `| a | b |`。
- 顏色標記（只標真正的重點，不要整段上色）：
  - `{{r|…}}` 紅：**考古題考過**。後面加年份，例如 `{{r|…}}（考113）`。判定來源：講義自己標註「考古／XX年」，或比對 Drive 中的考古題詳解（如「114年內專詳解.pdf」、「內專考古」資料夾）對得上的考點。
  - `{{p|…}}` 紫：講師強調、必背（講義寫「重要」「必考」「一定要記」或特別放大標示的）
  - `{{o|…}}` 橘：數字、cut-off、診斷標準、分期、劑量
  - `{{b|…}}` 藍：藥物、治療、首選處置
  - `{{g|…}}` 綠：口訣、鑑別診斷、對比記憶
  - `**…**`：關鍵字加粗（可與顏色混用：`{{r|**…**}}`）
- 圖片：考題附圖與「要看圖辨識」的臨床影像（皮膚病灶、X 光／CT／MRI、EKG、病理切片、血液抹片、內視鏡…）要截圖放進筆記，裝飾圖、logo、純文字投影片不要。
  - 存成 `data/img/<檔案id>/<流水號>.webp`（最長邊 ≤ 1400px、quality 80），在對應小標下獨立一行寫 `![說明：診斷／重點](img/<檔案id>/<流水號>.webp)`。
  - 說明要寫出這張圖的考點（例如「Erythema migrans：牛眼樣紅斑 → Lyme disease」）。
- 講師特別提示或考試陷阱用 `> ` 引言。
- 不要捏造講義沒有的內容；若補充了講義外的常識以利理解，在該行結尾加「（補充）」。
- 圖片或圖表中的重要資訊也要轉成文字。
- 講義是投影片時，依主題重組，不必照投影片順序逐頁寫。
